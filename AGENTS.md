# Toon Pro project instructions

Read [docs/ui-guidelines.md](docs/ui-guidelines.md) before creating or changing the interface. It records the artist's UI rules and supersedes older blanket slider/numeric-control guidance.

- Keep frequent actions direct and minimize clicks.
- Use recognizable icons by default, with tooltips after the shared 600 ms hover delay and accessible names; retain visible text where it is necessary for clarity.
- Use meaningful interactive visual widgets for complex settings. Keep sliders for suitable simple values and precise entry where useful.
- Use tabs for feature/category navigation, with icons where their meaning is clear.
- Follow the Adobe Spectrum-inspired color direction through shared semantic theme tokens.
- Current priority is the drawing workspace and UX. Animation is deferred until the artist returns to it.

Keep implementation status accurate in README and docs. Describe only controls and behavior actually implemented and verified. Current user instructions take precedence over repository guidance.
