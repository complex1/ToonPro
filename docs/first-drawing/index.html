Your first drawing

Go from the Projects screen to an editable canvas, make a mark and save it.

These instructions follow the current source build. Public 0.75 packages can differ.

Create a Drawing project

The current 0.76 entry flow begins with a project dashboard. The project name and its folder are separate from the name and dimensions of each drawing.

  1. Click New project on Projects.
  2. Choose Drawing, enter a project name and optionally choose Project location.
  3. Click Create project to open its drawing gallery.
  4. Click New drawing to configure the first canvas.

Set up the canvas

Choose Landscape, Square, Portrait or Custom. Width and height pair sliders with exact pixel entry. The aspect lock keeps the current ratio, and swap exchanges width and height. White, Transparent and Color backgrounds are available. A proportional preview shows the canvas before you create it. A colored background uses a locked raster layer; draw on the editable layer above it.

  1. Give the drawing a useful name.
  2. Choose dimensions and background.
  3. Check the live preview and click Create drawing.

Draw and save

Choose a group in Toolbox, then a tool in Tools. Set the foreground in Colors. Tool Properties exposes the current brush settings. With canvas focus, B selects Brush, E selects Eraser and H selects Hand. Space-drag pans and the wheel zooms. Cmd/Ctrl+Z undoes a committed edit.

  1. Select an editable raster layer.
  2. Paint a stroke and test Undo/Redo.
  3. Use Cmd/Ctrl+S or File → Save document.
  4. Return to Project dashboard to create another drawing.

Keep work in tabs

Several selected native items can open together with Open selected. Each tab retains its own dimensions, artwork, playhead, selection, view and Undo history. An asterisk marks unsaved artwork. Closing a dirty tab offers Save / Discard / Cancel; Cancel keeps it open. Open tabs stay in memory, so the useful count depends on the drawings and computer.
