Colors, swatches and gradients

Choose foreground/background colors, save reusable palettes and paint multistop gradients.

These instructions follow the current source build. Public 0.75 packages can differ.
In this chapterChoose a drawing colorSave named swatchesPaint a gradientKeep gradients editable where expected

Choose a drawing color

Colors provides an inline HSV picker and foreground/background chips. Brush tools use the current foreground unless a colored tip intentionally retains image colors. Eyedropper can sample the composite, active layer or a chosen reference artwork layer. With Eyedropper active, clicking/dragging an image in References samples that image; switch tools to return to ordinary reference panning.

Save named swatches

Use the palette chooser and plus action to save the current foreground/background color. The options menu creates, renames or deletes palettes and edits the selected swatch; right-click a swatch for its own commands. Selecting a palette alone does not change drawing color; clicking a swatch does. Global palettes are stored in palettes.json beside workspace preferences and are separate from project-owned Character Color Models. Limits are 64 palettes and 256 swatches each.

Paint a gradient

Linear Gradient and Radial Gradient are separate tools. Drag direction/distance on the canvas; radial begins at its center. The stop strip adds, moves, recolors, deletes and reverses stops, retaining between 2 and 32. Stop colors may include transparency.

  1. Select an editable raster layer.
  2. Choose Linear Gradient or Radial Gradient.
  3. Arrange stops; double-click one to choose its color.
  4. Drag on the canvas and release to commit through the active selection.

Keep gradients editable where expected

A committed gradient is raster paint, not a live gradient layer. Undo restores the previous artwork. Layer/folder locks, feathered selection and transparency restrictions apply. Color-range selection and fill tools use bounded raster sampling; they do not perform semantic subject recognition.
