Working product name: **Toon Pro**. Plan established on 13 October 2026 from the [requirements](requirements.md).

The [development checklist](TODO.md) is the active execution order agreed on 22 October 2026: video export with audio and camera animation first. The artist then moved effects/compositing, advanced motion and timeline improvements ahead of multiple-shot management. Build a useful, native desktop workflow in successive runnable milestones. Each milestone ends with a small real shot or character-design exercise. A complete anime production editor is a long-term product; this first implementation establishes project setup and the workspace.

## Stack decisions

| Area | Initial decision | Reason / validation needed |
| --- | --- | --- |
| Application and domain model | C++20 | Keep the painting, document and animation foundations in the same native language. |
| Desktop UI | Qt 6 Widgets | Native menus, dialogs, input and movable/tabbed/floating panels. Validate Huion behavior on both platforms. |
| Build | CMake, Qt Test, CTest | Repeatable builds and interaction tests on Windows and macOS. |
| Foundation sheet rendering | QPainter on QWidget/QImage | Sufficient for blank sheet layout and PNG exports. This is not the final painting engine. |
| Raster drawing | Tiled C++ image store and CPU stroke engine | Round and sampled tips, bounded memory and editable history. Choose the GPU integration after measuring the prototype. |
| Vector drawing | C++ path model, independently editable from raster strokes | Control points, stroke properties and transforms need a persistent model. |
| 3D | Filament 1.78.0 Metal worker with Qt canvas snapshots | Static GLB/glTF references, rest skeletons, skin correction and FK/IK posing are implemented on macOS arm64. Other renderer platforms remain unverified. |
| Audio and video | Qt Multimedia decoding, streamed PCM playback and H.264/AAC MP4 export | Audio and video use the Qt FFmpeg backend. Verify packaged codec distribution and Windows output before release. |
| Photoshop brushes | Dedicated ABR importer feeding the native brush engine | Specify supported ABR versions and settings from representative brush packs; do not equate importing a tip with Photoshop-equivalent rendering. |

The app is neither Python-based nor Electron-based. Python is used only for optional development tooling.

- Document placeholders and compatibility limits. Do not present a panel shell as a completed feature.
- Preserve work before convenience: atomic saves, recoverable asset writes, bounded parsing and destructive-edit history.
