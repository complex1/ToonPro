Drawing / LOCAL 0.76 SOURCE

Perspective guides and ellipse rulers

Place multiple editable geometric assistants and snap a brush path without changing the artwork.

These instructions follow the current source build. Public 0.75 packages can differ.
In this chapterPlace the right guideEdit directlyDraw with assistanceSave guide sets

Place the right guide

Press G or choose Toolbox → Guides, select a type and Add. Perspective uses four convex plane corners; Vanishing point one; Two-point two vanishing points plus an anchor; Parallel ruler two points; Three-point three noncollinear vanishing points plus an anchor; Fisheye two axis endpoints and height; Ellipse ruler the same three-point geometry for one fixed ellipse. Escape/right-click cancels placement.

Edit directly

Select a line, handle or list row. Drag individual geometry handles, or its center cross to translate the guide. Shift constrains supported handle drags; for ellipse height it creates a circle. List actions expose visibility, handle lock and snapping independently. Selected guide settings provide name, density where relevant, limited area and optional custom color/opacity. All guides contains shared appearance and snapping.

Draw with assistance

Enable shared Snap to guides and the guide snapping switch, then return to Brush/Eraser. Perspective/parallel directions are chosen after initial movement and stay fixed for that stroke. Fisheye follows a selected ellipse-family path. Fixed Ellipse captures contact within 12 logical screen pixels and follows its curve immediately. Native dynamics, pressure and stabilization remain available. Hidden or handle-locked guides can still snap if enabled.

Save guide sets

Guides save with their drawing and Undo history, and never appear in artwork exports. Save guide set writes .toonguides; Add guide set appends fresh IDs and adopts imported shared settings. Limits include 64 guides per shot, 256 per project, 1–64 density divisions and 1 MiB sets. Invalid geometry fails before replacement. No spline assistants, automatic three-point/fisheye inference or Krita assistant-file interchange is claimed.
