References / LOCAL 0.76 SOURCE

Light Table and shift-and-trace

Pin movable source-preserving snapshots over the canvas and flip between reference poses.

These instructions follow the current source build. Public 0.75 packages can differ.
In this chapterPin a referencePlace and compareSave embedded snapshotsCapacity and exit behavior

Pin a reference

Open References → Light Table. Pin the current layer, a drawing/folder from a shot or an imported image. Each pin is an explicitly labeled snapshot. Later source edits do not silently alter it; Refresh is the deliberate update. Removing a pin leaves the original source untouched.

Place and compare

Enable Move/rotate/scale to use canvas handles. Exact position, scale, angle and opacity rows sit beside sliders. Reset restores placement. Visibility combines pins; Previous/Next enables solo reference viewing without changing the active drawing.

  1. Add a pin from the desired source.
  2. Select it and enable placement editing.
  3. Align its pose using handles or exact controls.
  4. Exit pin editing to draw through the overlay.
  5. Flip or solo pins to compare construction.

Save embedded snapshots

Pins save embedded pixels, transforms, opacity, visibility, selected pin, solo and overall visibility. They reopen without needing the imported image file. Deleting a source drawing leaves the snapshot usable; Refresh requires the source again. Pins never contribute to artwork exports. Saving/closing handles changed aids as project state, while ordinary artwork Undo preserves current aids.

Capacity and exit behavior

Up to eight snapshots share a 64 MiB pixel budget, fitted to 2,048 pixels per side. Source images retain original resolution. 3D and adjustment-only sources are not supported. Space/middle pan stays available; Escape or hiding the panel exits pin manipulation. Finish a placement/import gesture before Save. The overlay is a drawing aid, not a live linked layer.
