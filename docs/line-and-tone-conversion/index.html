Drawing / LOCAL 0.76 SOURCE

Convert images to lines and tones

Prepare independent raster linework and shading with preview, cleanup controls and retained originals.

These instructions follow the current source build. Public 0.75 packages can differ.
In this chapterPrepare and compareTune extracted linesChoose shading outputWork on the resultBoundaries

Prepare and compare

Import an artwork image or select a visible drawing layer. Choose Edit → Convert to line art or the layer context action. Select Lines only, Cel shading, Manga tones or Grayscale. Source/Result compares before committing. Lines/Shading/Output changes prepare background previews; Create layers generates full-resolution output before atomic publication. Cancel leaves the drawing untouched.

Tune extracted lines

Detail adjusts edge sensitivity; Width controls fractional-pixel line thickness; Denoise suppresses grain; Smooth follows edge directions; Dust removes small fragments; Line color chooses ink and alpha. Background cleanup applies useful architectural-photo starting values while preserving output/colors. Reduced previews trade detail for responsiveness; inspect created layers at 100% before judging final line quality.

Choose shading output

Cel shading produces separate middle and deep shade regions. Grayscale produces a shade layer. Manga tones produces raster dot patterns with spacing/angle and two noncrossing tone thresholds. Image darkness is not separated semantically into material and lighting; a dark object may enter a shadow band. There is no inferred geometry or relighting.

Work on the result

Output is an ordinary raster group with optional Base, Shadows, Deep shadows and Lines. Hide original after conversion is reversible; a locked source remains locked and visible. Generated layers can be painted, masked, transformed, saved and reopened. Source/folder/Notes membership is retained. One Undo restores the original stack and visibility.

Boundaries

Canvas processing is limited to 9,437,184 pixels and 16,384 per side, plus project tile/layer/history budgets. Only artwork-frame content is generated. Output is a snapshot: no retained recipe, vector lines, temporal batch conversion, live screentone layer or regeneration link. Direct 3D input and geometry-aware conversion are deferred. A rendered 2D screenshot from a model can be processed as an ordinary image.
