Animation / LOCAL 0.76 SOURCE

Draw and time one animation shot

Use existing drawing exposures, holds, templates, onion skin and local playback in an independent document.

These instructions follow the current source build. Public 0.75 packages can differ.
In this chapterStart from the current dashboardChoose drawings and holdsEdit exposure timingUse drawing aids and playbackBounded shot workflow

Start from the current dashboard

Create an Animation project, then New animation with name, canvas, FPS and frame count. The focused editor opens one independent shot with an initial Simple drawing track. In an existing compatible document, Panels → Timeline and its plus action manage frame-by-frame/static tracks. UI frames begin at 1. Existing animation is available; drawing workspace/UX remain the current development priority.

Choose drawings and holds

New blank drawing uses the selected layer template. Duplicate drawing creates independent artwork. A Hold exposes one drawing for several frames; editing it changes all uses. Reuse existing drawing exposes an existing track drawing at an empty interval. Its picker includes names, thumbnails, labels, usage counts and unused drawings. Removing an exposure retains source artwork; explicit unused-drawing deletion is separate.

Edit exposure timing

Shift/Cmd/Ctrl selects ranges or individual cels; blank-grid dragging creates a marquee. Drag bodies to move a selection, Alt+Left/Right nudges, and a single exposure can trim its edges. On 1/2/3 applies common holds sequentially per track. Copy/paste, Repeat and Reverse preserve shared drawing references as described by the command. Collisions, locks or invalid ranges reject the batch atomically. Ordinary cel timing does not retime property keys, camera or audio.

Use drawing aids and playback

Onion settings provide previous/next distinct drawing counts, color and opacity; holds/reused copies are skipped. Ghosts use evaluated artwork through the current camera and stay out of export. Playback ranges rehearse a section; Center playhead scrolls without changing artwork. Preview quality can trade resolution for playback responsiveness. Heavy sources/effects may run below target FPS.

Bounded shot workflow

Current limits include 16 exposure tracks, 256 drawings and 16,384 exposures per shot, within project tile/history/container budgets. Drawing containers support raster/vector and compatible Symbol content; text/3D remain outside them. Focused manager tabs intentionally exclude multi-shot collection review and lock audio/video export to current-shot scope. They do not become a full movie editor.
