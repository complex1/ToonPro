Manage and import brushes

Find the built-in collection, create independent brushes and inspect import compatibility.

These instructions follow the current source build. Public 0.75 packages can differ.
In this chapterBrowse the catalogCreate and organizeImport ABR packs carefullyUse image tips

Browse the catalog

Open Panels → Brush Management or Tools → More → Manage brushes. Search, category, type and tag filters narrow the same list. Browsing metadata does not select a painting tool until Use or double-click. The current built-in collection contains 219 original Toon Pro configurations; these are native recipes, not assets borrowed from other drawing applications.

Create and organize

New brush starts from Pen, Ink, Soft brush, Spray, Stamp, Colored stamp, Dynamic stamp or Custom. Current brush copies the active configuration. Supply a name and optional category/tags/destination group. Multiple selected brushes can receive tags/categories or group membership. Duplicate creates independent settings. Organization Undo/Redo is separate from artwork Undo. Deleted definitions stay deleted after restart; existing drawings retain their captured resources.

Import ABR packs carefully

Import reads supported sampled/computed tips and modern ABR descriptors. Preset names match sample UUIDs, including several presets sharing one tip. Supported geometry, spacing, selected shape/transfer/scatter controls map into the native engine. Compatibility details report mappings, clamps, defaults and skipped fields. Texture resources, source dual-brush/color definitions, bristle/wet mixing and exact Photoshop rendering remain unsupported. Damaged known descriptors fail without partially changing the library.

Use image tips

Image stamp import accepts PNG, JPEG, WebP and BMP within bounded size/dimension limits. Normal Stamp uses alpha or inverted luminance as foreground coverage; Colored stamp retains source pixels and transparency. The original file is unchanged. Native brush definitions and captured vector sources embed their required images. The catalog shares tool/resource budgets, so a very large personal library can defer new defaults instead of replacing existing settings.
