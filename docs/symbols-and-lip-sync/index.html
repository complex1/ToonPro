Animation / LOCAL 0.76 SOURCE

Reusable Symbols and manual timed poses

Share source artwork while keeping each instance placement and playback clock independent.

These instructions follow the current source build. Public 0.75 packages can differ.

Create and place shared artwork

Symbols convert supported selected artwork into a reusable definition owned by the current native document. Place instances through the Symbol library, and edit the shared source in its editor. Changes update instances that reference it. Conversion checks reject unsupported sources instead of silently flattening them. Each instance can retain independent layer transforms, opacity and playback settings. Independent dashboard documents keep separate native Symbol libraries; shared-source behavior applies inside the owning payload.

Control a clip clock

Timeline Symbol clips expose finite timing with Start, Hold, Slip, First frame and supported playback modes. Moving/trimming a clip changes its instance exposure without duplicating shared source. Visual frame pickers show actual source drawings. Reusing a drawing within one animation track and placing a Symbol across supported contexts are separate workflows.

Place manual mouth or expression poses

Select a Symbol clip and Frame Properties → Symbol → Poses. At a frame inside the clip, use the timed-pose action to select a source drawing visually. The pose holds until the next key or clip end; before the first key the instance holds First frame. Its Poses lane shows held intervals and supports ordinary key selection/move/nudge/copy/paste/delete. Each instance owns its keys; artwork remains shared.

Use cues for timing references

Timeline markers and dialogue ranges label shot timing. Marker types include Marker, Key pose, Breakdown, In-between and Dialogue; these do not create artwork or mouth keys. Dialogue text, waveform and audible scrubbing guide manual pose placement. No automatic speech recognition, phoneme inference, subtitle exchange or automatic lip-sync is implemented.

Timing and ownership limits

Poses uses an unscaled clip clock; Speed is disabled while its playback value remains stored. Trim/slip/move preserve applicable keys under explicit clock rules. Ripple rejects visibility splits/clocks it cannot represent atomically. Nested definitions and sources share project limits. Symbols are owned by their native document, not a live global cross-project asset service.
