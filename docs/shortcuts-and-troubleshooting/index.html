Shortcuts and troubleshooting

Find common canvas commands and diagnose restrictions without guessing about lost artwork.

These instructions follow the current source build. Public 0.75 packages can differ.

Everyday canvas shortcuts

B: Brush. E: Eraser. H: Hand. G: Guides. T: Transform pixels. Space-drag or middle-drag: pan. Wheel: zoom. Shift+M: mirror working view. Tab: drawing mode panel visibility. These act in the appropriate canvas/editor context; text fields retain ordinary editing.

Cmd/Ctrl+S: save document. Cmd/Ctrl+Z: Undo. Platform Redo: redo artwork. Cmd/Ctrl+A: Select All; Cmd/Ctrl+Shift+I: invert; Cmd/Ctrl+D: deselect. Cmd/Ctrl+X/C/V: cut/copy/paste; Cmd/Ctrl+Shift+V: paste into active layer; Cmd/Ctrl+J: duplicate selected pixels.

Enter applies a pending transform when canvas focus is active; Escape cancels an active gesture or preview according to its tool. In editable artwork text, Cmd/Ctrl+Enter commits and Escape cancels. A shortcut label shown by your platform/menu is authoritative when keyboard layouts differ.

Why a tool cannot draw

Check the active layer type, visibility, folder locks, alpha lock and any retained Puppet Warp. Bucket/gradient/retouch need raster destinations. Vector geometry tools need a compatible vector source; painting a retained warp requires Bake or reopening its pins. The forbidden cursor/status reason explains known restrictions without a modal alert. Panning, selection and sampling often remain available while painting is blocked.

Where the work went

A hidden folder hides descendants; a clipped layer needs a valid visible base in its own group. Timeline Solo is preview-only and respects saved visibility. A held/reused drawing shares artwork across exposures. An active selection can confine a stroke to a small area. An imported image and its initial positioning are separate Undo operations; cancelling positioning does not remove the layer. Use History to inspect retained edits, and save before reorganizing important projects.

Build, media and recovery checks

CMake cannot find Qt: confirm the SDK contains Widgets/SVG/Concurrent/SQL/Multimedia and set CMAKE_PREFIX_PATH to its platform directory, not a random include folder. Missing Qt Test affects testing builds. Reconfigure after changing optional runtime inputs.

No audio/video preview or MP4 encoder: check the packaged Qt Multimedia backend and actual codec availability. A source file can be retained even when local decoding is unavailable.

Project already open: another writer lease is active. Do not bypass its catalog protections to force simultaneous editing. Missing/corrupt catalogs should be investigated, not replaced with an empty database. Reopen recovery when offered and use saved-state backups for independent copies.

Report useful evidence

Record the app/source version, platform, selected tool/layer, steps, expected result and actual status/error text. Save a small reproducible project when possible. Source tests and synthetic tablet events cannot certify physical tablet feel. The current validation report states automated results and remaining native/device/platform acceptance separately.
