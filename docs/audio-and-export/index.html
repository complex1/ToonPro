Output / LOCAL 0.76 SOURCE

Sound, images and video export

Import shot-local audio, finish its mix and render the evaluated frame using supported codecs.

These instructions follow the current source build. Public 0.75 packages can differ.
In this chapterImport and mix audioRehearse against soundChoose the right imageVideo and mixed soundExport limits

Import and mix audio

The Audio workflow imports supported local files through Qt Multimedia, decodes to embedded 48 kHz stereo signed 16-bit PCM and shows waveform clips. Place/trim clips in shot time. Volume, mute and overlapping clips affect playback/export through the same mixer. Fade handles offer Linear or Equal-power curves; gain keys automate volume. Existing overlaps can receive crossfades without moving either clip.

Rehearse against sound

Playback uses a supported audio device clock; unavailable or stalled output warns and continues visual playback silently. The Timeline speaker enables remembered audible playhead scrubbing, with short coalesced grains only during ruler drags. Numeric frame entry stays silent. Audio source speed is unchanged when frame-based placement or project FPS changes; time stretching, microphone recording and beat detection are absent.

Choose the right image

Export movie frame PNG writes the evaluated output/camera frame and excludes editor paper/header, Notes, onion skin and handles. Export production sheet PNG includes the sheet presentation. Export animation PNG sequence writes each shot frame into a newly named folder, with progress/cancellation and existing-file protection. Native current reference-3D layers use their shared render/export path; legacy reference-only scenes retain their historical behavior.

Video and mixed sound

Export video MP4 uses the Qt Multimedia FFmpeg backend and checks H.264/AAC encoder availability at runtime. No external ffmpeg command runs from the app. Current focused tabs export their current shot; older movie collection workflows are not exposed as a new editor in the manager. Mixed audio WAV uses 48 kHz stereo PCM with fades, trims, keys, mute and overlaps. Background work supports progress and cancellation.

Export limits

Codec/device support follows the platform/runtime. macOS source validation is not proof of Windows packaging or encoder acceptance. AAC may add a short padded audio tail while retaining exact video frame count/placement. Large outputs share document/effect memory budgets. PNG sequence cancellation may leave completed frames; those are intentional completed outputs, not a fully atomic sequence. Keep native saved artwork before rendering delivery copies.
