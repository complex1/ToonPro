Advanced brush dynamics

Shape native marks through response curves, scattering, texture, symmetry and deterministic variation.

These instructions follow the current source build. Public 0.75 packages can differ.
In this chapterOpen the advanced editorShape the markDistribute texture and colorKeep source and replay distinct

Open the advanced editor

Click the wrench in Tool Properties to open Advanced brush settings. Vertical category tabs switch setting groups directly; a short heading identifies the current page. Edits immediately affect subsequent strokes. Close keeps committed changes. The active category is remembered, and advanced views synchronize when reopened.

Shape the mark

Tip shape includes a primary tip choice, rotation, roundness, flips and spacing. A direct tip preview edits rotation and squash; a stamp strip shows spacing. Shape dynamics vary size, angle and roundness through available pressure, direction, tilt, fade or other supported inputs. Response graphs expose movable control points and presets. Transfer separately controls opacity/flow response. These map to native engine behavior rather than decorative previews.

Distribute texture and color

Scattering/count distribute repeated impressions. Texture uses pattern thumbnails, scale/position controls and supported native coverage modes. Dual brush combines a secondary mask with the main tip. Color dynamics vary applicable HSV/color channels. Pen pose controls supported tilt/direction overrides. Symmetry presets and a draggable center produce linked copies. Deterministic seeds keep captured vector replay reproducible.

Keep source and replay distinct

Brush-resource settings and captured tip images travel with editable vector strokes. Changing a tool later does not rewrite existing strokes. Editor input stabilization preferences are separate from the resources needed to replay a recorded stroke. Unsupported imported ABR texture/dual/color definitions are not silently reproduced by the native controls.
