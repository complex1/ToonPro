Drawing / LOCAL 0.76 SOURCE

Retained Puppet Warp

Deform raster artwork with free pins, reopen its mesh later and bake only when ready to paint.

These instructions follow the current source build. Public 0.75 packages can differ.
In this chapterCreate a pin deformationKeep the original sourceBake for ordinary paintingCurrent constraints

Create a pin deformation

Choose Edit → Puppet Warp or Warp → Pins on a raster layer, selected raster layers or a folder. A triangular mesh covers rectangular artwork bounds, including transparent gaps. With a pixel selection it moves the selected source region. Density 4–32 sets mesh cells along the longer side; density changes retain current pins.

  1. Add fixed pins near areas that should stay in place.
  2. Add a movable pin and drag to deform the preview.
  3. Shift-click to select several pins and move them together.
  4. Alt-click or Delete selected pins to remove them.
  5. Apply/Enter commits one Undo; Escape cancels the preview.

Keep the original source

Apply retains original raster tiles, mesh bounds, density and up to 64 pins on each affected layer. Saving/reopening preserves them. Reopen with Edit Puppet Warp in Layers or the Pins inspector. Changes render again from the same original, avoiding repeated resampling. Reset restores shape while retaining pins. Reopening and applying an unchanged mesh creates no history entry.

Bake for ordinary painting

Retained warps protect source/generated pixels from painting, erasing and other pixel transforms. You can adjust the mesh and keep layer opacity/effects/organization available. Edit → Bake Puppet Warp keeps the present appearance and removes stored mesh/source so ordinary raster editing can resume. One Undo restores the retained source.

Current constraints

Raster only; rasterize vector/text first. Invalid folds, collapsed triangles, boundary crossings and out-of-range coordinates retain the last valid preview. Stored source tiles count against the project tile/container budgets. There is no per-pin rotation, mesh expansion, overlap ordering, silhouette-derived mesh or pin animation. A saved deformation is not an animation rig. Older builds cannot open files requiring retained-warp format 40.
