Drawing / LOCAL 0.76 SOURCE

Selections and clipboard artwork

Constrain painting, save named boundaries and copy transparent pixels with their placement.

These instructions follow the current source build. Public 0.75 packages can differ.
In this chapterCreate and combine selectionsUse selection actionsCopy and place pixelsImport artwork separately from references

Create and combine selections

Rectangle, ellipse, polygon, lasso, magic wand and color-range choices create raster coverage. Tool Properties exposes New (replace), Add, Subtract and Intersect, plus Feather 0–100 artwork pixels. The active selection is workspace state: it does not dirty artwork, export or persist after reopen. Up to 64 named selections per shot retain geometry and feather in the project with Undo support.

Use selection actions

Select All, Invert and Deselect are available from Select; the floating selection action bar exposes common operations close to the canvas. Brush, eraser, fill, gradient, retouch and clipboard extraction honor coverage and feathering. A boundary-only transform changes the selection without moving pixels. Color tolerance tools are bounded image operations rather than AI subject/hair selection. The floating bar can follow the selection or be pinned by its grip. More offers foreground fill, clear and Expand/Contract by 1–100 pixels. View-only outside shading and border animation help inspect coverage without changing exports.

Copy and place pixels

With canvas focus, Cmd/Ctrl+X/C/V cut, copy or paste into a new layer. Cmd/Ctrl+Shift+V pastes into the active raster layer; Cmd/Ctrl+J duplicates selected pixels. Internal placement metadata keeps original coordinates, including negative overscan. External images default to frame center. Vector/text copying produces pixels while retaining its original editable source.

  1. Select the source layer and desired area.
  2. Copy or cut; alpha and feather coverage are retained.
  3. Paste into a new layer, or use Paste into active layer.
  4. For a new layer, position it with the basic transform and Apply/Cancel.

Import artwork separately from references

File → Import image as artwork layer adds a supported image as a new editable raster layer and starts positioning. Cancelling the placement keeps the imported layer; Undo removes the import. Asset import and References import have different ownership/export behavior. Artwork/clipboard sources are bounded to 64 million pixels and the document layer/tile budgets.
