Meet Toon Pro

A native drawing workspace with independent documents, practical reference tools and an existing short-shot animation foundation.

These instructions follow the current source build. Public 0.75 packages can differ.

What the product does

Toon Pro is a C++20 and Qt 6 desktop application for drawing, inking, painting and developing hand-drawn work. Raster paint and editable vector strokes share a drawing workspace. Project dashboards keep documents and reference materials organized separately from the canvas.

The current source identifies itself as 0.76.0. These guides describe that local development build. Public 0.75.0 preview packages use an earlier project flow and do not acquire new features merely because this website has been updated.

Choose a document workflow

Drawing projects collect still images. Animation projects collect independent single-shot animation documents. Movie projects organize both kinds with folders and tags. Every project has a separate Assets collection.

  1. Start with Drawing if you want to sketch or paint.
  2. Create one drawing and choose its canvas and background.
  3. Open more documents in tabs when useful.
  4. Add timing inside an animation document when you need it.

Read capability labels honestly

Available means implemented in the current local source; it does not mean every platform package has passed acceptance. Development highlights newer 0.76 workflows that are absent from public 0.75 packages. Optional means an additional runtime or build capability is required.

Drawing workspace and UX remain the current priority. Existing animation features are documented so they remain usable; this is not a promise of new animation work, a completed movie production pipeline or feature parity with established applications.

Known product boundaries

A global cross-project asset library, simultaneous cloud editing, automatic dependency tracking and a finished multi-shot delivery pipeline are not implemented. Pricing and application licensing have not been decided. Tablet feel, production-size workloads and additional platforms require acceptance beyond source tests.
