Paint checks and guided cel shading

Inspect raster flats and draw explicit shadow/highlight boundaries before applying reversible results.

These instructions follow the current source build. Public 0.75 packages can differ.
In this chapterCheck flat colorsReview repairsDraw shading boundariesResume unfinished work

Check flat colors

Panels → Cel Paint Check analyzes checked raster drawings for enclosed holes, disconnected islands, edge-reaching fill leaks and off-palette colors. Choose a character/lighting palette or disable palette checks, then set tolerance and repair-size limits. Problems navigates issues and source exposures. The canvas highlights an issue while the panel isolates its drawing.

Review repairs

Check only intended problems. Preview fills small holes with foreground, erases selected stray/leak regions and maps off-palette pixels to nearest approved RGB. Show original compares each drawing. Apply commits one batch Undo; Cancel discards it. These are heuristics: intentional negative space, detached details and frame-touching backgrounds can be flagged. Analysis reads raw raster artwork inside the frame, not vector paths or composited effects.

Draw shading boundaries

Panels → Cel Shading uses a transparent raster outline source. In Boundary mode draw explicit Shadow/Highlight guides, then use Fill inside regions closed by the outline and guides. Guide tint is independent from final paint color. Boundary finish either removes the centerline or takes the adjoining region color across its width. Edge-reaching open regions are rejected.

  1. Choose an outline source.
  2. Draw the desired guide boundaries.
  3. Select shade colors and fill closed regions.
  4. Review the preview and apply.
  5. The app creates Shadows/Highlights raster layers beneath the outline as one Undo.

Resume unfinished work

Shading drafts retain their source shot/layer/frame, guides, fills, colors and operation order when saved. Switching drawings keeps separate drafts; return to resume. Source edits rebuild previews rather than deleting drafts. Apply clears the completed draft; Cancel clears the current draft. Draft step-back is separate from artwork Undo. Checks and shading enforce explicit pixel/issue/path limits and destination locks.
