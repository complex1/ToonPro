References / LOCAL 0.76 SOURCE

Editable 3D references on the canvas

Place and pose reference models inside a native layer, draw above them and save editable scene sources.

These instructions follow the current source build. Public 0.75 packages can differ.

Place and draw

Open View → 3D reference or the editor toolbar cube. Library contains Models, Poses and Materials; Controls holds scene settings. Body, Head, Hand, Anime and Pets include proportion studies, Seed-san/Alicia, dog/cat/eagle and supported pose presets. Select a model and Place model, double-click or Enter. From an artwork layer this creates a reference layer; selecting one extends its scene.

  1. Place a model in a drawing.
  2. Choose Translate, Rotate, Scale, Pose or Camera and All/X/Y/Z.
  3. Drag model/joint handles directly on the drawing canvas.
  4. Use Draw above to create/select a raster layer and return to Brush.
  5. Save the drawing normally to retain models, pose and camera.

Pose and shape deliberately

FK rotates local joints. Supported connected hand/foot endpoints use basic two-bone IK with target/pole controls; positive uniform chain scales are required. Body/hand pose presets apply in one Undo while preserving placement and shape. Finger Curl/Spread target supported sides/fingers. Shape pages adjust supplied body/head/hand studies; compatible mixtures and exact entries edit the same scene. Imported morph/expression controls expose only data actually present.

Import and reuse local sources

The importer accepts a supported subset of GLB/glTF/VRM, retaining hierarchy, skins, bounded weights, morphs and canonical assets. Scenes import/export as .toon3d. Typed local materials reuse scenes, characters, poses, compatible shapes and cameras, with search/favorites. Source data is self-contained; placed scenes do not require the original download. Unsupported semantics/formats are reported rather than silently flattened.

Rendering and storage

Native 3D layers belong to drawing Undo and save/recovery revisions. Completed object/pose/camera drags commit once; Escape cancels. Visibility, opacity, order and folder composition integrate with the drawing. Direct pixel paint, merge/flatten and direct layer filters/masks protect canonical source. A bounded software Base-color preview renders transparent pixels; it preserves PBR/MToon data without claiming full shader evaluation. Current native layer rendering contributes through the shared compositor and export path.

What remains open

This workspace supersedes retired legacy skeleton-building/weight painting. It is not full CSP parity, full VRoid body/hair authoring or production GPU rendering. Image-to-pose capture, hand-camera scanning, spring physics, advanced shaders/lighting, general full-body IK, broader exchange formats and arbitrary asset retargeting remain open. Anatomy, extreme deformations, production-size models and physical pen/platform behavior require acceptance. Explicit TOON_ENABLE_EXPERIMENTAL_3D=OFF builds omit authoring controls.
