Connected brushes, surface patterns and tones

Draw joined ribbons and repeats, paint phase-stable patterns and use explicit perspective mapping.

These instructions follow the current source build. Public 0.75 packages can differ.

Connect a motif along a curve

Advanced → Tip shape offers Stamps, Ribbon and Repeat. Connected modes map the primary image along joined path segments. Size sets strip width with supported pressure/size/speed response. Repeat length sets the motif distance relative to width; Ribbon also uses image proportions. Complete repeats can choose among tip frames and alternate-flip them. Moving after contact builds the strip; contact alone does not place the complete motif.

  1. Choose a compatible catalog brush or your own image-tip brush.
  2. Open the wrench → Tip shape and choose Ribbon or Repeat.
  3. Adjust Size, Repeat length and optional Alternate flip.
  4. Draw a curve, then inspect its tightest corners before committing a production pass.

Keep connected controls distinct

Connected marks use flow, opacity, blending, selection, alpha lock, symmetry and continuous canvas texture. Ordinary stamp spacing, count/scatter, root anchors, tip angle/roundness/projection, hardness, stationary airbrush, dual masks, each-tip texture, wet edges and noise are not connected-strip parameters. Their saved values remain available when returning to Stamps. Adjust stamp is unavailable in connected mode. Very tight reversals can compress motifs; an architectural brush does not redesign its windows/posts for corners.

Paint native tones

Patterns and tones offers Dots, Lines, Crosshatch, Diamond, Noise, Fade dots and Image. Frequency is cycles per 100 artwork pixels, not print LPI. Density controls coverage independently; angle/offsets position the pattern. Fade dots adds an end density and fade length along pattern Y. Fixed-seed Noise uses a cell grid. A tone retains phase across impressions and strokes; repeated dabs inside one stroke do not turn its antialiased grid into solid paint. Separate strokes still alpha-composite normally. Minified patterns average coverage; exports remain artwork-pixel based.

Map image surfaces explicitly

Image mode imports a repeating tile with its colors/alpha without replacing the brush tip. Tile width/height choose artwork-pixel repetition. Perspective plane maps the source onto a convex four-corner quad. Drag its corners in the preview or use X/Y exact entry. Fit to artwork explicitly fits the current output frame, respecting camera mapping and excluding production margins/header. It does not run automatically when selecting a preset. Outside the quad stays transparent. The plane is a 2D mapping, not a live link to guides or a 3D camera.

Add specialized dynamics

Scattering → Clustered spray replaces ordinary scatter offsets with cluster count, radius, spread, bias, span and direction while preserving the captured seed. Color dynamics → Foreground tint moves a colored tip toward foreground hue/saturation while retaining shading and transparency. Transfer → Speed response changes size/opacity from timestamped artwork-space speed; signed controls determine how fast marks change. Speed samples are captured for vector replay, independent of event batching and working zoom.

Source and quality limits

Raster and editable vector marks share the renderer. Captured images, seed, repeat phase and speed samples stay with vector source, independently of later library edits. Joined edges prevent duplicate flow buildup and use transparent source sampling across repeat boundaries. Large connected strips/surfaces still consume CPU and shared image/tile budgets. These features do not add physical pigment/bristle simulation, automatic print-DPI conversion or verified physical-tablet latency.
