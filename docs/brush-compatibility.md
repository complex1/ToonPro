# Brush presets and Photoshop import — 0.35.0

Toon Pro has a reusable local brush library, native advanced brush settings and a Photoshop ABR importer. Supported modern descriptors supply preset names, sampled or computed round tips, and selected settings to the native paint engine. The compatibility report identifies transferred settings, limits and unsupported features; this is not a complete Photoshop brush engine. The native controls are documented in [Brush settings](brush-settings.md).

## Native presets

The starter library contains **19 original native presets**. Round Ink, Round Sketch and Round Blocking keep their earlier settings. Sixteen additions cover hard/pressure round brushes, airbrush, G Pen, fine liner, graphite/mechanical pencil, charcoal, dry ink, flat/soft paint, pigment wash, particle spray, stipple, chisel marker and calligraphy. See the [starter-brush table](brush-settings.md#standard-starter-brushes) for individual behavior. New additions receive the **Standard** tag and family/category metadata when first installed; existing edits and deletion records are preserved. Their small native masks and textures are generated locally, with no third-party brush assets.

Existing custom presets and imported samples are retained in the local `brushes.json` library. Libraries read versions **1–4**. Saves use version **4** when a custom preset contains extended dynamics (a nondefault response curve, once-per-stroke jitter, Rotation control or seed configuration); otherwise they use version **3** for colored stamps or **2** for grayscale presets. A library that fails validation is preserved and cannot be overwritten in that session.

Each brush is an individual tool in **Toolbox → Drawing → Tools**. Tool Properties adjusts it directly; the tool remembers its current configuration in `tools.json`. **Duplicate** creates independent settings, including smoothing and primary/colored/texture/secondary images. **Rename** changes its name; the navigation panel’s **Remove** only removes a placement. **Brush Management → Delete** removes the brush definition from every group and standalone placement, with separate organization Undo/Redo. Source presets remain cached in `brushes.json`; saved deletion records in `tools.json` suppress automatic recreation. Artwork is unaffected. Adding an existing tool to another group shares its settings. Switching tools preserves foreground/background colors and restores that tool’s own texture settings. The previous Brushes dock is incorporated into this flow.

Open **Panels → Brush Management** or **Tools → ⋯ → Manage brushes…** to create Pen, Ink, Soft brush, Spray, Stamp, Colored stamp, Dynamic stamp or Custom brushes, copy the current brush, and organize names, categories and tags. Search/tag/category/type filters and multi-selection support batch organization. New manager-created brushes are stored in the tool catalog. Use its **Import** button or either navigation panel’s overflow menu to **Import Photoshop brushes…**. Imported templates retain source and compatibility information in `brushes.json`; the manager offers import details beside the result, and navigation-menu imports show a report dialog. They appear in Drawing if that starter group still exists and remain available in Add Tools. The catalog and brush library are separate from movie files.

## Image stamp support

The manager also imports PNG, JPEG, WebP and BMP images: at most 32 MiB, 8192 pixels per source side and 33,554,432 source pixels. Copies are reduced to at most 2048 pixels per side, preserving proportions to pixel rounding. Normal stamps use alpha coverage when transparency exists, or inverted luminance for opaque images, and paint in the foreground color. Colored stamps preserve RGBA image colors and alpha; opaque backgrounds remain opaque. Empty stamps are rejected.

Colored stamps support native tip geometry, pressure/rotation inputs, response curves, random variation, softness, transfer, scattering, texture, selection and editable vector replay. Their Color Dynamics controls are disabled because foreground/background and HSV jitter do not recolor the embedded image. Color stamps are native image imports; ABR does not import colored tip pixels.

## ABR support

| Feature | Current behavior |
| --- | --- |
| ABR versions 1 and 2 | Reads sampled brush records. |
| ABR versions 6.1, 6.2, 10.1 and 10.2 | Reads sampled-tip resources and supported version-16 action descriptors. |
| Eight-bit samples | Imports raw and PackBits-compressed pixels. Coverage 0 is transparent; 255 is opaque. |
| Version 2 names | Reads the stored UTF-16BE sample name. |
| Modern preset names and sample association | Reads names from supported descriptors and matches sampled tips by their stored UUID, never by list position. Several presets may share one tip while retaining separate settings. Missing or repeated identifiers never assign a preset to an arbitrary sample; unreferenced supported tips remain available with native defaults. |
| Names without supported descriptors | Version 1 and modern packs without usable descriptor metadata retain numbered filename-based names. |
| Large sampled tips | Smoothly resizes to at most 1024 pixels on the longest edge, preserving proportions to pixel rounding and at least one pixel per side. Original and imported dimensions appear in the report and saved preset compatibility notes. |
| Tip geometry | Maps diameter, angle, roundness, spacing and static flips where present. Computed round brushes also map hardness and do not need a sampled resource. Values outside the native range are clamped and reported. Disabling spacing is not reproduced. |
| Shape dynamics | When enabled in the source, maps size, angle and roundness jitter, supported input controls, minimum values, fade steps, tilt scale and projection into native settings. Random tip flips are not transferred. |
| Transfer and paintbrush options | When enabled, maps opacity/flow dynamics. Recognized paintbrush tool options map base opacity and flow. Smoothing, blend modes, other tool overrides, wetness and mixing dynamics are not transferred. |
| Scattering | When enabled, maps amount, both axes, scatter input/fade, count and count jitter/input/fade. Nonzero scatter/count minimum settings are unsupported and reported. |
| Input control mapping | Off, Fade, pressure, tilt, stylus wheel, initial direction, direction and barrel rotation map to native controls. Photoshop initial rotation is unsupported and reported. Hardware-dependent controls still require a capable pen/driver. |
| Computed bristle/custom brush geometries, 16-bit samples, other compression | Skips them and reports the unsupported feature. Only computed round geometry is mapped. |
| Fully transparent tips | Skips them with a report. |
| Pattern textures, dual brushes, color dynamics, brush-pose overrides, noise, wet edges and build-up timing | Not transferred. Enabled recognized features appear in the compatibility report; native defaults remain in effect. |
| Unrecognized descriptor version or binary value type | Uses supported sampled tips with a warning and native defaults. It does not guess offsets or apply partially read settings. Computed-only packs require supported descriptors. |
| Unsupported versions | Rejects the file with a supported-version message. |
| Damaged records or exceeded resource limits | Rejects the entire import; the existing library remains unchanged. |

The import report lists each preset's mapped settings, range limits and recognized unsupported features. Unspecified fields use native defaults; unrecognized Photoshop features are not promised to transfer. Source flags gate dynamics, so disabled source dynamics stay disabled. Imports without usable descriptors retain the previous sampled-tip defaults, including pressure-controlled size. Imported tools use the catalog's Imported category; Photoshop folder/category hierarchies are not reconstructed, and the artist can organize categories and tags in Brush Management.

Each saved imported preset keeps the source filename, ABR version and a file-content SHA-256/sample identifier. Catalog duplicates retain the native settings and images; original import provenance remains in the source brush library. Imported ABR files and native libraries are read locally; no brush data is uploaded.

## Rendering and limits

Sampled tips retain their proportions before optional roundness, projection and angle transforms, and also work with the eraser. The engine evaluates native shape, texture, dual-tip, color and transfer dynamics for individual stamps, accumulates flow within the stroke opacity cap, and blends the result against the original active-layer pixels. Dab spacing is carried across input events; an entire stroke remains one undo step. Sampled-tip size denotes the longest edge. The pointer traces tip coverage instead of always showing a circle, with a 20%-of-peak contour for soft masks.

The current engine paints at 1–256 px nominal brush size. New ABR imports retain up to 1024 pixels on the longest edge, four times the maximum painting size. Existing native masks up to 2048 pixels per side remain supported. The source brush library allows 128 custom presets with a 64 MiB resource budget; grayscale pixels count as one byte and colored pixels as four. The tool catalog has its own 64 MiB image budget, including group icons. Brush-library and catalog files are bounded to 96 MiB and 128 MiB respectively. Grayscale PNG resources permit up to 6 MiB each; colored PNG resources permit up to 17 MiB.

ABR input is limited to 256 MiB, 128 sample records, 8192 pixels per source side, 268,435,456 decoded source pixels and 67,108,864 imported pixels per pack. Mapped presets plus unmatched tips may total at most 128 brushes. Recognized version-16 descriptor resources total at most 8 MiB; other descriptor versions are skipped as opaque sections within the 256 MiB file bound. Parsed descriptors have limits of 128 presets, nesting depth 20, 32,768 values, 4,096 fields per object and 4,096 UTF-16 code units per string. Source masks are decoded and resized one at a time. Malformed known records, duplicate descriptor fields, nonfinite values or exceeded limits reject the entire import atomically. The original ABR is never modified. Vector projects have a separate 16,000,000-pixel embedded brush-resource budget (at most 64,000,000 decoded bytes for RGBA); importing a library does not increase that project limit.

Project files retain raster pixels and embed the resources used by editable vector strokes, so opening artwork does not need the original ABR or brush library. Editable vector strokes with extended dynamics require at least project format **21**; colored vector-stroke resources require at least **20**. Other project features can require a newer format, including scene metadata in **22** and audio finishing in **23**. Raster pixels alone do not require a newer format. Tool catalogs use version **7** only when a tool configuration contains extended dynamics; otherwise they retain version **6**, including brush metadata, colored resources and deletion records. Existing supported formats remain readable, and newer fields are rejected in older version declarations instead of being silently discarded. Editable presets are machine-local and should be backed up separately.

Response curves, once-per-stroke jitter and fixed seeds are native settings. They are available through **Advanced brush settings → Shape dynamics / Transfer / Texture**, with seed controls in **Behavior → Randomness**. Fixed-seed replay depends on the same path and input samples; it is not a promise of identical results for independently drawn gestures. Speed-controlled dynamics, bristle physics and wet-pigment simulation are not implemented. Native Pigment Wash is a textured low-opacity brush. None of these additions changes the ABR import coverage listed above or establishes Photoshop/Krita/Clip Studio Paint/Procreate rendering equivalence.

## Validation and next work

The parser tests include independently constructed raw and PackBits fixtures for every supported version, asymmetric coverage, oversized-tip resizing, file/source/output budgets, malformed rows and atomic rejection. Descriptor fixtures cover names matched to reordered samples, shared and ambiguous identifiers, computed round brushes, enabled/disabled dynamics, settings/limits reports, unsupported fallback and malformed input rejection. A library save/reload test checks mapped sampled and computed presets. These fixtures are not Photoshop exports. Optional local-pack checks use `TOON_ABR_PACKS_DIR` with `toon_abr_packs_tests`; they never copy third-party brush artwork into the repository. Physical Huion input and Windows acceptance remain pending.

On 26 October 2026, the artist's **Free Brush Stroke Photoshop Brushes** (ABR 10.2, 15 tips) and **Free Watercolor Washes Photoshop Brushes 7** (ABR 6.2, 15 tips) passed the existing local-pack check again with the descriptor importer: sequential import into one temporary library, tool-catalog save/reload, raster/vector painting parity and an individual vector-project save/reload for every tip. All 30 tools survived and source SHA-256 hashes were unchanged. That check validates import, painting and persistence for these packs; it does not assert every source descriptor setting or compare original Photoshop appearance. Name/settings mapping is covered separately by constructed fixtures and the library integration test.

Further compatibility work should use representative files and comparison renders before adding additional sampled encodings, pattern resources, dual-brush mapping or other descriptor fields. No full Photoshop rendering-equivalence claim is made.

The implementation was written independently using format facts checked against primary upstream sources: [Adobe's descriptor format specification](https://www.adobe.com/devnet-apps/photoshop/fileformatashtml/), [ag-psd's ABR field mapping](https://github.com/Agamnentzar/ag-psd/blob/master/src/abr.ts), [GIMP's ABR reader](https://github.com/GNOME/gimp/blob/master/app/core/gimpbrush-load.c), [Krita's ABR collection reader](https://invent.kde.org/graphics/krita/-/blob/master/libs/brush/kis_abr_brush_collection.cpp), [Krita's mask conversion](https://invent.kde.org/graphics/krita/-/blob/master/libs/brush/kis_brush.cpp), and [Krita's brush-tip documentation](https://docs.krita.org/en/reference_manual/resource_management/resource_brushtips.html). No GPL implementation code or third-party brush artwork was incorporated. Fixture provenance is recorded in [the fixture notes](../tests/fixtures/abr/README.md).
