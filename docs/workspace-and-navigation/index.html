Arrange the drawing workspace

Keep the canvas central while opening the tools and panels needed for the current task.

These instructions follow the current source build. Public 0.75 packages can differ.
In this chapterKnow the control surfacesNavigate without changing artworkArrange and remember panelsUse responsive property controls

Know the control surfaces

Toolbox is a fixed-width icon column for groups and standalone tools. Tools is a resizable dock with named rows and proportional previews. Tool Properties changes with the active tool. Layers, Colors, Navigator, References, Effects and other optional panels use ordinary docks. Hover icon controls for 600 ms to see their names and shortcuts; keyboard focus and accessible names identify the same actions.

Navigate without changing artwork

Wheel zoom, Space-drag and middle-button pan are working-view actions. Fit sheet and Actual size are available in View. Shift+M toggles a view-only mirror. View rotation and mirror change input mapping and presentation rather than saved pixels. The AA control toggles canvas display smoothing; it does not alter export quality or document history.

Arrange and remember panels

Open panels from Panels, drag docks into stacks or tab groups, or float them. Tab drawing mode hides/restores working panels. The Illustration/Anime arrangements keep drawing controls close to the canvas. Named personal workspace layouts can be saved, updated, reloaded and managed. Focused document tabs intentionally exclude Shots and Scene/Movie review navigation. Resolve active gestures or unfinished exact entries before switching layouts.

Use responsive property controls

Simple scalar settings provide a slider with adjacent exact entry. Spatial controls use canvas handles or meaningful previews where implemented. Enter commits numeric text without invoking the dialog primary button; Escape cancels that numeric edit. A completed document-backed drag normally creates one Undo command. Temporary tool/view changes remain separate from artwork history.
