Projects, folders and assets

Organize native drawings, independent shots and imported media without flattening editable sources.

These instructions follow the current source build. Public 0.75 packages can differ.
In this chapterFind and organize projectsUnderstand the three dashboardsImport mediaMove, remove and restore

Find and organize projects

Projects offers search, name/last-opened sorting, grid/list views and All projects, Pinned and Archived filters. Pinning and archiving change the recent-project presentation. Removing a recent entry does not delete its files. Opening a project returns to its dashboard, without automatically opening every document.

Understand the three dashboards

Drawing shows drawings; Animation shows independent shot documents with duration and FPS; Movie shows mixed content with nested folders and tags. Every project has Assets. The Assets destination has folders, type/tag filters and a selected-item inspector. Grid/list choices are remembered by project type and collection. Saved native frames and imported images generate real thumbnails asynchronously; audio/video cards use source-kind icons.

Import media

The importer copies files into generated project-owned paths, retains the external originals and publishes the batch only after it succeeds. Cancelling before publication leaves no visible partial batch.

  1. Open Assets → Import assets.
  2. Choose Add files and inspect the file rows.
  3. Remove unwanted files, choose a destination folder and optional batch tags.
  4. Confirm the import, then select an item for its preview.
Keep in mind

Images preview asynchronously. Video/audio require Play and support Pause, Stop and seek; selection never autoplays.

Codec availability depends on the local Qt Multimedia runtime. A retained source can exist even if preview decoding fails.

Move, remove and restore

Move to Assets changes collection/folder/tag metadata for the same item ID and source path. A native drawing remains editable and open tabs remain valid. Edit tags/folder, Rename, Remove and Restore are available from item actions. Organization Undo is separate from artwork Undo. Remove retains original bytes and saved revisions; there is no permanent-delete UI. Asset-to-document placement, live links, a global library and folder reparent/rename controls are not implemented. Native character, palette and Symbol libraries live inside individual document payloads; moving a drawing into Assets does not synchronize those libraries into other drawings.
