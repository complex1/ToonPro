Animation / LOCAL 0.76 SOURCE

Property keys, motion and cameras

Animate supported layer properties independently from drawing exposure timing.

These instructions follow the current source build. Public 0.75 packages can differ.
In this chapterEnable a property channelChoose interpolation and pathsAnimate effects and masksFrame with a shot cameraRetime the whole shot carefully

Enable a property channel

An existing layer/folder can retain position X/Y, scale X/Y, rotation and opacity keys. Enable the corresponding diamond, move the playhead and adjust the property. Frame Properties/Timeline offers previous/add/delete/next and exact key time. Key selection, drag/nudge/copy/paste operate as validated Undo batches. Source artwork mode edits the underlying content without confusing it with the evaluated pose.

Choose interpolation and paths

Hold, Linear, Ease in, Ease out and Ease in-out are supported; custom outgoing easing graphs provide more control. Canvas motion paths and spatial handles edit supported paths, with pivot and Follow path orientation where applicable. Compatible vector path keys can morph matched topology; the app does not automatically match unrelated drawings or infer in-betweens between arbitrary shapes.

Animate effects and masks

Effects diamonds enable supported scalar/switch channels while retaining source values. Numeric blur/shadow/glow/color and mask placement/opacity/feather channels use existing interpolation. Enable/invert switches hold. Mask paint and effect colors remain shared source data, not frame drawings. Frame Properties separates Transform, Effects and Mask categories. Outline does not add its own animation channels.

Frame with a shot camera

The existing camera controls support framing and 2D/3D camera pose keys in shot documents. Camera output differs from working-view pan/zoom/rotation. Exact pause and export evaluate camera plus layer/drawing properties consistently. Reference-3D scene navigation is separately owned by its reference layer and is not a general rig/model animation feature.

Retime the whole shot carefully

Ripple time inserts, deletes or moves a range across exposures, property/path keys, cameras and audio. Preview validation rejects unrepresentable Symbol clocks, locks and count overflows before changing anything. It can split holds/audio while preserving source references. Ripple is whole-shot timing; ordinary cel drag changes exposures only. Custom camera curves, full value graphs and arbitrary multi-segment Symbol time remapping remain open.
