Layers / LOCAL 0.76 SOURCE

Layers, folders and compositing

Control the stack with direct visibility, lock, blend, clipping and organization actions.

These instructions follow the current source build. Public 0.75 packages can differ.
In this chapterRead the layer stackSet appearance and protectionOrganize a structureComposite and merge carefully

Read the layer stack

Topmost artwork appears first. Rows show visibility, a checkerboard thumbnail or type badge, name and relevant lock/Notes/clipping marks. Eye clicks do not change the drawing target. Dragging through the eye column sweeps visibility as one Undo; Escape cancels. Double-click names to edit inline. Folder carets collapse children. Row colors are organizational marks and do not tint paint.

Set appearance and protection

Blend modes are Normal, Multiply, Screen, Overlay, Darken, Lighten, Color Dodge, Color Burn, Hard Light, Soft Light, Difference and Exclusion. Opacity has a live slider and exact entry. Full lock protects content/structure; alpha lock preserves existing raster coverage; position lock permits painting while protecting geometry/organization. Folder locks propagate. Notes exclude their descendants from movie-frame output while allowing production-paper annotation.

Organize a structure

Select ranges with Shift and separate rows with Cmd/Ctrl. Drag selected rows to reorder or drop inside a folder; insertion feedback shows the destination. New Folder wraps selected siblings. Duplicate preserves independent source content and folder structure. Delete supports Undo. Clipping runs must move with their base when necessary. Limits include 64 nodes per static stack/drawing and eight folder levels.

Composite and merge carefully

Folder children composite in isolation, then folder opacity/blend applies once. Clipped siblings use the nearest unclipped base in the same group and preserve its coverage. Merge Down combines eligible visible unlocked Normal raster siblings; incompatible clipping, Notes or blend cases are refused. Flatten Image bakes visible content while preserving a separate Notes result when valid. Hidden paint is omitted; transparency is retained and editor paper is not baked. Undo restores editable structure.
