# Drawing tools

The drawing workspace includes color sampling, area painting, shapes, expanded selections, retouch brushes, clipboard images and advanced transforms. Vector layers retain editable brush strokes using the same renderer as raster brushes. Text has a standalone tool and inline canvas editing. Native 3D reference models and static posing support drawing; the legacy rest-skeleton/weight authoring UI is retired. Frame-by-frame raster animation, layer property keys, compatible vector path morphs, audio and synchronized preview are available. These are native Toon Pro implementations; exact Photoshop, Clip Studio Paint or Krita output equivalence is not claimed.

Drawing tools act on the current exposed drawing. Sampling and reference-layer choices exclude inactive drawings; held frames share the same artwork. Blank intervals require a new drawing, and playback must be paused before editing. Independent vector and text layers support property animation, and compatible vector paths support morphs. 3D content remains static. See [frame animation](animation.md).

The local 0.76 drawing workspace also adds persistent [Fill reference marks](fill-reference.md) and [perspective detection from layers or local images](perspective-detection.md). References supply fill boundaries while the active raster layer receives color. Detected perspective is reviewed and corrected before becoming ordinary editable, snapping guides; neither operation replaces source artwork.

## Reusable Symbols (0.65.0)

Use **Panels → Symbols**, or **Layers → right-click → Convert to symbol**, for reusable 2D artwork and animation. Linked instances share their definition within the native document while retaining independent placement and playback. Double-click a library entry to edit its contents; **Save changes** updates every linked copy with one Undo. **Make unique** separates one instance, and **Break apart at current frame** returns editable layers for the displayed internal frame. See the [complete Symbols workflow](symbols.md) for timing, conversion constraints and project storage.

## Finding tools

Choose a group or standalone tool in **Toolbox**. **Tools** shows that group’s members or exactly one standalone tool. Its Add dialog offers searchable tools and brush previews; right-click tools to Duplicate, Rename or Remove. Each tool remembers its settings, and explicit Duplicate makes an independent copy. The main toolbar contains project and view commands. With canvas focus, **B** selects Brush, **E** Eraser, **I** Eyedropper, **F** Paint bucket, **D** Gradient, **M** Rectangle selection, **L** Lasso, **T** Transform, **G** Perspective guides and **H** Hand. Shortcuts restore the last-used tool for that engine and synchronize both panels. The Vector Editing group adds Path Edit, Simplify Brush, Width Brush and Vector Eraser. Drawing brushes work on either raster or vector layers. A dedicated Bézier Pen entry remains outside the catalog.

Tool Properties follows the active tool. Its dock is labeled **Properties**, with the active tool name in its tooltip. Icons have accessible names and the shared 600 ms tooltip delay. Spatial operations use canvas handles; exposed scalar settings pair a visible slider with a compact field for exact entry. In 0.37, labels share the row where space allows and wrap above the controls in narrower panels. Resizing preserves unfinished numeric entries. Only the active drawing inspector determines its scrolling height. Enter finishes a path or applies a transform; Escape cancels the current gesture; when idle it clears the current raster selection.

### Mirror the canvas view — local 0.76

Use the **Mirror canvas view** arrows in the project toolbar, **View → Mirror canvas view**, or **Shift+M** with canvas focus. This reflects the view horizontally along the canvas axes, including its artwork, guides and selection handles. Zoom, rotation and center are retained. Drawing and sampling use the reflected coordinates; tablet tilt, twist and the brush-tip outline follow the view. Toggle after releasing an active pointer drag or pen contact; attempts during contact leave the view unchanged.

Mirroring is view state for that editor tab, separate from artwork Undo, saved pixels, camera keys and exports. Other tabs keep their own view. Opening a document starts unmirrored; this toggle is not saved into the project or a global preference. Ordinary **M** still selects Rectangle selection.

### Steadier brushes — local 0.76

The brush Properties header offers **Smooth / Strong** modes beside the existing drawing controls. The **Smoothing** value remains 0–100. Smooth uses a moderate distance filter; Strong selects a pulled-string Stabilizer with greater trailing distance. Both measure distance in logical view pixels, including camera zoom, so zooming out no longer reduces the same setting to only a few screen pixels.

Open **Advanced brush settings → General** to tune the Stabilizer's **Dead zone** (0–20 view pixels) and **Finish stroke** policy. Finish is on by default and follows retained path history on release; off stops at the stable tip. Mode, tuning and view scale are latched at contact, and settings are remembered per tool. Large strength values deliberately trade detail and responsiveness for steadiness. The existing Smoothing checkbox and strength zero retain direct input. See [research, algorithm choices and practical settings](stroke-stabilization.md); CSP-equivalent output or physical-tablet latency has not been certified.

### Ellipse snapping assistant — local 0.76

Choose **Guides → Ellipse** to place a fixed rotated ellipse using its axis endpoints and height handle. Move the whole guide from its center. Enable the existing **Snap to guides** setting and begin a brush stroke near the ellipse; capture uses a 12-view-pixel distance and puts the first dab on the curve. Strokes remain curved across the ellipse seam and repeated revolutions. Visibility, locks, guide limits, Undo and project/guide-set saving use the existing assistant workflow. This is separate from the filled Ellipse shape tool and the fisheye guide family. [Ellipse guide details](guides.md).

Tools has a tag filter and name/tag search for the current group. **All tags** shows its full membership; **Untagged** shows members with neither personal nor current-group tags. A group tag matches all its members in that group without overwriting individual tags. Filtering keeps the active painting tool, even if its row is hidden. The no-match state provides **Clear tool filters**. Choose **⋯ → Icons only** for a compact grid with name tooltips; reorder tools in the unfiltered named list.

Open **Panels → Tool Management** or **⋯ → Manage tools** for Groups/Tools tabs. Groups supports creation, names, tags, color swatches, built-in/uploaded icons and a checked membership chooser. Tools supports selecting several definitions and adding/removing one tag or changing their label color together. Right-click navigation rows for quick tag assignment. Colors label the interface and do not alter brush paint. Metadata/name edits have organization Undo/Redo, preserve the current drawing tool and persist locally; icon view/filter choices are remembered with the workspace. Supported group images are PNG/JPEG/WebP up to 8 MiB / 4096 × 4096 pixels, fitted to at most 256 × 256 while preserving transparency. See [tool-management requirements](requirements.md#tags-and-tool-management).

Version 0.61 adds **Cel Paint Check**, **Cel Shading** and **References → Light Table**. ## Character Color Models

In **Panels → References → Color Models**, select an existing character or create one with **+** beside the character name. The same character entries appear in Model Sheets, and selecting a character in either collection updates the other. **Skin / Hair / Costume / Shadow** tabs organize named swatches such as Base, Highlight, School uniform or Face shadow. Narrow panels show category symbols with names available through the shared delayed tooltips and accessibility labels.

Click a color row, or select it and press Enter, to use that exact color and opacity as the drawing foreground. Browsing characters/categories does not change the foreground. The color-row **+** stores the current foreground under a name; **Replace** updates the selected swatch from the current foreground. **Edit color** opens the existing color picker with hexadecimal entry and an opacity slider/number pair. OK records one change; Cancel leaves the swatch unchanged. Hex input accepts `#RRGGBB` or `#AARRGGBB`, with alpha first.

The name field renames the selected swatch. Enter or leaving it commits; Escape restores the previous name. Right-click a swatch to rename it, move it to another category or remove it. Removal, color edits and character changes use document Undo/Redo. Save commits pending color and model-sheet names before taking its snapshot; Close resolves names before deciding whether to show the unsaved-changes prompt. Invalid names prevent that operation and remain editable for correction.

Palettes live once per character in the movie project, remain available in every shot and survive save/reopen. The original Day colors use normalized 8-bit RGBA and were introduced in project format 28; older files open without adding or changing palette data. Character models without colors or variants can keep format 27, and other projects retain their compatible format unless a newer saved feature requires it. Each character supports 256 shared swatches, with 8,192 across the project. The global artist palettes in Colors remain separate. Swatch selection copies a color into the brush; palette edits do not relink or recolor already-painted artwork. Version 0.64 adds explicit previewed batch recoloring below; automatic linked recoloring remains future work.

### Lighting variants in 0.63.0

The scrollable lighting-palette tabs sit above Skin / Hair / Costume / Shadow. **Day** is the base palette. New characters also receive **Night**, **Sunset** and **Interior**, initially containing the same colors as Day so the artist can define each lighting treatment. An older character retains its original colors as Day; use **Lighting palette options → Add missing lighting palettes** to create missing standard palettes from Day. Adding presets never replaces an existing palette of the same name.

The palette-row **+**, or **Duplicate palette…** in its options menu, copies the current palette under a new name. Rename and Remove operate on additional palettes; Day stays available. Each palette stores independent RGBA values for the same swatch roles. Renaming or moving a swatch between categories changes that role everywhere; editing its color changes only the selected palette. Adding a swatch initializes it from the foreground in every palette. Removing a swatch removes the role from every palette. Undo restores palette and role changes.

The selected palette is remembered per character across shot changes during the open session. Reopening the project starts on Day, with all saved palettes available. Explicit character/palette navigation updates the approved palette in Cel Paint Check; its own chooser can select any character/variant independently. Palette browsing does not change the foreground until a swatch is used.

Variant definitions require project format 30 and coexist with model sheets, Light Table pins and shading drafts. A character supports 16 additional palettes; all Day and variant colors together are limited to 65,536 entries per project. Names must be unique within the character, ignoring case, and Day is reserved. The 0.63 storage, document, panel and workspace regressions pass, together with native Mac and offscreen 2× checks. Lighting tabs keep natural label widths and scroll when space is limited; narrow/custom names and larger text were visually reviewed.

### Recolor selected drawings in 0.64.0

The **Recolor drawings…** paint-bucket button opens a preview dialog for the selected character and lighting palette. Choose **From** to match the palette already painted, and **To** for its replacement. Check individual raster layers from the current shot or all shots, including animation drawings exposed on other frames. Only the active drawing is checked initially; hidden/locked drawings and folders, notes and non-raster sources cannot be edited here.

**Preview** runs in the background. Select a prepared drawing to compare **Before / After** while keeping its zoom and pan. **Apply** commits all checked replacements in one Undo; **Cancel** or Escape leaves the source pixels unchanged. Matching is by shared role color, with original pixel alpha retained, including antialiased coverage; palette alpha does not change opacity. Narrow opaque antialiased edges between identifiable palette colors are recolored too. Unrelated colors and broad blends remain untouched, and conflicting source-role mappings report an error. The raw-paint preview excludes compositing and effects. See [cel coloring](cel-coloring.md#previewed-character-recoloring-in-0640) for bounds and stale-preview safeguards.

## Character Model Sheets

In **Panels → References**, **Images** contains the current shot's references; **Model Sheets** contains the project's shared character library. Add a character with **+**, then select **Turnarounds**, **Expressions** or **Costumes** and import one or several images. Select another character from the name list. The pencil renames a character; the character-row trash removes that character and its sheets. Undo restores removed content.

Thumbnails select a sheet; a single image uses the full viewer without a redundant thumbnail strip. Edit its name beside the import button. Enter or leaving the field commits the name; Escape restores it. Right-click a thumbnail or the image itself for **Rename**, **Move to** another category, or **Remove model sheet**. The viewer provides drag-to-pan, wheel zoom, Fit and precise zoom entry. Alt-click, or the active Eyedropper, samples a color for drawing.

All shots share the same character records and embedded images. Changing shots preserves the current model-sheet selection, zoom and pan. Browsing creates no history entry and never adds a reference to exported artwork. Each completed library edit is undoable; a multi-image import is a single operation and leaves the library unchanged if any file fails.

PNG/JPEG/BMP imports accept sources up to 32 MiB, 16 million pixels and 16,384 pixels per side, then fit copies within 2048 pixels per side. The source files remain unchanged. A project supports 128 characters, 256 sheets and 64 million decoded sheet pixels, separately from shot-reference limits. Project format 27 embeds the shared library; older projects open without a library, and projects without characters continue using their previous compatible format. This library is shared within one movie project; an application-wide library and simultaneous pinned views are not part of this version.

## Editable stamp placement

Version **0.47.0** adds editable stamp placement. In **0.47.1**, **Tool Properties → Adjust stamp** shows a labeled **On/Off** toggle whenever Brush has a sampled grayscale or colored tip. Stamp and Colored Stamp tools start with it enabled. Other sampled brushes can enable it explicitly; ordinary ink, texture and spray strokes keep their existing default workflow. The choice is remembered per tool and copied when that tool is duplicated. Turning it off places any pending stamp at its current transform, then returns to continuous brush strokes. If placement fails, the toggle stays On and keeps the pending stamp available to fix or discard.

Tap the canvas to create one brush impression. Pen movement during that first contact does not paint a trail. After lifting, drag inside the bounding box to move the stamp, a corner to resize it proportionally, or the round handle above the box to rotate it. Shift while resizing allows independent width/height. The existing transform sliders and precise fields are also available in Tool Properties. Enter or the floating checkmark places the stamp; Escape or Cancel discards it. Clicking outside the box and its handles confirms it and begins the next stamp. Switching tools asks Apply / Discard / Cancel even if the new stamp has not moved. Apply or cancel before saving.

Only the new impression is transformed. Existing pixels and vector objects remain fixed. Sampled colors, pressure, blend mode, opacity and the chosen random seed/tip are captured at contact; subsequent placements can vary normally. Scatter/count or symmetry copies produced by that contact move together. The document's selection stays fixed while the stamp moves and continues to clip it; alpha lock is respected. Move beyond the sheet and back without losing the source; the raster result is clipped only when placed. A fully clipped placement adds no invisible object or Undo entry.

Raster layers receive pixels on confirmation. Vector layers retain an editable brush object. Each completed placement is one Undo step; cancelling adds no artwork history. Hold-to-shape, guide-constrained strokes and modifier line gestures belong to continuous brushing: switch placement off to use them. Transform drags coalesce preview work at a 16 ms timer interval; this is not a frame-rate guarantee for large or complex stamps.

## Hold to shape

Version **0.46.0** adds a hold gesture to Brush and the raster Eraser. Draw a line, arc, circle, ellipse, rectangle or triangle, then keep the pen down and pause for **0.7 seconds**. When a supported shape fits the gesture, the canvas previews a clean version using the current brush. Lift the pen to see thumbnail choices along the bottom of the canvas. Click a shape to keep it, choose **Original** to restore the freehand stroke, or use Cancel / Escape to discard the stroke. The suggestions depend on the drawing; arbitrary scribbles need not produce a match.

Moving the pen again before lifting resumes the original freehand stroke. Starting another stroke, switching tools or saving accepts the current fitted preview. Each completed stroke is one Undo step. Pressure, tip texture, seed, selection and symmetry use the existing brush engine; vector layers retain an editable brush stroke. Original restores the original pixels and captured stroke state, including stabilization. This gesture does not add post-fit node handles or drag-to-resize controls.

The **Hold to shape** wand icon beside the brush wrench turns the gesture on or off and remembers the choice across sessions. It starts enabled. It ignores ordinary pen micro-jitter, tiny marks, airbrush dwell, active guide snapping and Command/Ctrl/Shift-constrained strokes. Fitting runs after the pause, with bounded input sampling; normal pen delivery remains unchanged. Expensive large textured brushes can still take time to redraw a fitted preview.

Interaction references: [Procreate QuickShape](https://help.procreate.com/procreate/handbook/5.1/guides/quickshape) for draw/hold and candidate choices, and [Clip Studio Paint curved lines](https://help.clip-studio.com/en-us/manual_en/450_figure/Curved_lines.htm) for the Arc gesture below. These are Toon Pro implementations, not imports of either application's engine.

## Straight brush strokes

Version **0.45.1** adds modifiers to the existing Brush and raster Eraser; no separate line tool is needed:

- Hold **Command or Ctrl before contact** to draw horizontally or vertically. The first clear movement (three view pixels) chooses the axis; contact jitter does not choose it. The axis stays fixed for that gesture, including backtracking. Axes follow the artwork when the view is rotated.
- Hold **Shift before contact** to preview a straight line at any angle from the contact point to the current endpoint. Moving the endpoint replaces the previous preview. Pen-up commits the final endpoint immediately. Pressure and pen pose interpolate from initial contact to the current endpoint; the curved route taken by the pen is not retained.

The modifier choice is captured at contact and lasts until pen-up, even if the key is released earlier. Command/Ctrl wins if combined with Shift. Each gesture is one Undo operation; Escape restores the artwork, and a tool change or focus loss finishes the current gesture. Existing Alt color sampling and Space/Hand navigation keep their behavior.

Both modes use the current brush engine, including sampled/colored tips, deterministic tip variation, symmetry and selection clipping. Brush strokes on vector layers remain editable. Raster erasing is supported; the separate vector eraser/correction tools keep their existing gestures. Guide snapping and stabilization are bypassed for these constrained strokes. Shift previews are coalesced at a 16 ms timer interval and retain one random seed, so changing the endpoint does not reshuffle the brush. Timer pacing is not a guarantee of 60 fps for expensive large stamps. Airbrush dwell is disabled for the adjustable Shift line; axis-locked strokes retain normal airbrush behavior.

## Sampling, filling and gradients

**Eyedropper** samples the visible layer composite, active layer, or a chosen reference *artwork layer*. Each individual tool remembers its own source choice. A reference artwork layer is a layer in the layer stack, distinct from an imported image in References. While Eyedropper is selected, clicking or dragging on an image in the **References** panel samples its image pixels into the foreground color. Reference panning resumes after switching tools.

**Paint bucket** uses the clicked pixel as its seed. Tolerance ranges from 0–255. **Close gaps** ranges from 0–20 pixels and uses a square morphological closing operation on detected boundaries. It can seal small breaks in line art; it is not an inference system for completing arbitrarily open drawings. Sampling can use all visible layers, the active layer or a chosen reference artwork layer, while paint is applied to the active raster layer. Existing selection coverage and transparency lock constrain the result. The bucket recovers the adjacent antialiased edge up to two artwork pixels, preserving opaque line cores. On the ink layer it replaces the background contribution; a separate color layer fills beneath reference edges. Broad blurred boundaries can still need manual cleanup.

In local **0.76**, Bucket properties have **Point / Enclose** tabs and an **Expansion** slider with exact entry. Expansion ranges from **−20 to +20 artwork pixels**: positive values grow beneath sampled outlines, negative values shrink the filled area, and zero retains the existing edge recovery. Growth preserves ink owned by the painted layer and does not jump into disconnected matching background regions. Composite sampling conservatively protects existing destination ink; explicit recoloring is available for already-painted edges. For underpainting opaque outlines, use a separate raster destination and sample the outline with the existing source controls, including [marked fill references](fill-reference.md). Expansion and the selected fill mode are remembered independently by each saved tool.

Choose **Enclose**, then drag a freehand loop around several closed regions to fill them in one gesture. Source boundaries determine the filled regions; the loop itself does not close an open drawing. Only regions wholly inside the loop are filled. Open regions, the outside background, and regions cut by the loop are skipped. This first version targets transparent or white-paper line art; opaque colored areas are treated as boundaries, so use Point mode to recolor existing flats. Tolerance, gap closing, expansion, raster selections and layer locks still apply. Mouse and pen commit on release as one Undo step. Escape, lost contact or focus interruption discard the unfinished loop.

Enclose samples at most **16,777,216 pixels**, with at most **8,192 gesture elements** and bounded scanline work. Oversized or overly fragmented input is refused without a partial edit. It is not semantic coloring of photographs or textured paintings. Point fills with expansion can be recorded in Auto Actions; enclose fills stop an active recording as an unsupported artwork operation.

**Linear Gradient** and **Radial Gradient** are separate Tools entries. Drag on the canvas to set direction and distance; the radial mode uses the starting point as its center. The stop strip supports adding, moving, recoloring, deleting and reversing stops. Double-click a stop to choose its color, including transparency; use the foreground button to assign the current drawing color. At least two and at most 32 stops are retained. Gradient paint commits to the raster layer on release, through the current selection and layer locks. It is not a separate live gradient layer.

Flood operations and color selections sample at most 32 million pixels per operation. Oversized or excessively fragmented requests fail without changing artwork. Visible Notes layers participate when sampling the layer composite.

## Lines, shapes and paths

Line, Rectangle and Ellipse use a drag to define the shape. Hold Shift for square/circle proportions or 45-degree line directions. Polygon uses successive clicks and finishes with Enter or by closing at the starting point. The four-click Curve tool defines a cubic Bézier segment: start, first control, second control and end.

Version **0.46.0** adds **Arc** to Shapes and Add Tools. Drag from the start to the end, lift, then move the mouse or hover the pen to bend the live curve. Tap/click the third point, or press Enter, to commit; Escape or Backspace cancels. The quadratic curve passes through that third point halfway along its parameter. Raster layers receive painted pixels; vector layers receive an editable path using the existing shape stroke/fill controls. The existing four-point Curve tool remains separate. Arc is added once to older tool catalogs, preserving custom groups and subsequent removal.

Tool Properties has independent fill/stroke switches, fill color and a slider-and-entry stroke width. The foreground color supplies the stroke color. On a raster layer, shapes commit pixels in one undo step. On a vector layer they become editable paths. Raster painting respects selection coverage; editable vector paths remain whole objects rather than being destructively clipped to pixel selections.

## Selections and their display

In addition to Rectangle and freehand Lasso, selections include Ellipse, Polygonal lasso, Magic wand and Color range. Wand selects the connected matching area; Color range selects matching colors throughout the sampled drawing area. Tolerance and sampling-source controls work like bucket settings, with independent values per tool. Gap closing is meaningful for connected flood regions, not global color-range matching.

New/Add/Subtract/Intersect modes remain available. Shift adds, Alt subtracts, and Shift+Alt intersects while creating supported selection shapes. Selection actions include Select All, Invert, Expand/Contract, Fill and Clear. Dense selections use bounded pixel coverage for these geometry operations. While adding/subtracting/intersecting a shape over a dense selection, the gesture previews the new shape and combines it on release. Requests beyond the detail or working-area limit show a message and preserve the previous selection.

**Feather** ranges from 0–100 artwork pixels and creates graded edge coverage through a box-filter mask. Painting, erasing, fills, gradients, retouching, clipboard extraction and pixel transforms use that coverage. The dashed boundary displays the selection geometry rather than every partially covered pixel. A transform retains the feather radius in artwork pixels.

Name and save a selection in Tool Properties, then recall it through the list. Saved selections retain geometry and feather radius in the project; a shot can contain up to 64. Saving the same name replaces that saved entry. Saving, replacing and deleting entries participates in undo. The current unsaved selection and view handles are editor state.

The selection appearance controls independently toggle moving borders and outside shading, and adjust shade strength. Existing following/pinned/hidden floating toolbar controls remain available. These display settings do not modify image pixels or PNG exports. An empty active selection still exposes Deselect and Invert in the floating toolbar. Escape clears an idle selection, and Select → Deselect (Cmd+D on macOS / Ctrl+D on Windows) remains available.

## Advanced transforms

Use **Select → Transform selected layers / perspective / warp** to transform the Layers panel selection. A selected folder includes its drawing descendants. The existing **T** tool remains available for basic raster move, scale and rotation; editable vector/text layers, selected groups and multiple selected layers route to the advanced transform.

Perspective Transform and Warp are individual Toolbox entries. Their property controls offer:

- **Distort / perspective:** drag the four corners of a projective quadrilateral, or drag away from a handle to translate the whole selection.
- **Warp → Grid:** drag any of nine control points in a 3×3 mesh. The mesh consists of eight affine triangles, rather than a smooth spline or liquify surface. Grid warp rejects selections above 4,096 path elements with a message before starting; use Perspective Transform or deselect first. This prevents costly triangle clipping of highly fragmented Color Range selections.
- **Warp → Pins / Edit → Puppet Warp… (local 0.76):** place control pins anywhere inside a density-controlled triangular mesh and drag them to deform raster artwork while other pins hold. Density, Show mesh, Delete pins, Reset and Apply/Cancel stay in Tool Properties. [Puppet Warp workflow and limits](puppet-warp.md).
- **Flip horizontal/vertical** and skew preview controls.
- **Layer/folder content** or **selection boundary only** as the target.
- Explicit Apply and Cancel, also available through Enter/Escape and the Select menu.

Source tiles remain unchanged during pointer previews. Move, scale, rotate or distort artwork beyond the drawable area and bring it back before applying; the pending artwork remains visible beyond the paper while it is within the workspace view. Apply generates full-resolution raster pixels, cropping the moved content to the drawing extent (including configured overscan and Notes margins). Fully outside raster content is removed at Apply, with Undo restoring it. An applied selection boundary is clipped to that same extent, and a wholly outside selection clears so drawing can resume. The operation becomes one undo step. Groups, individual layer identities, blend modes, opacity and clipping relationships are preserved. Selection-boundary-only transforms leave every artwork pixel untouched and can be undone.

Leaving a changed transform for another tool opens **Apply / Discard / Cancel**. Apply commits and switches; Discard restores the original artwork and switches; Cancel keeps the current tool, settings and preview. A failed Apply also keeps the pending transform. Choosing a transform without changing it does not prompt. Escape explicitly discards the current transform; Space panning leaves it pending.

Matrix transforms preserve editable vector paths and text objects. Their rendered pixels are clipped on Apply, while the source geometry remains editable and can be moved back into view; rasterize first when permanent pixel cropping is required. Mesh warp requires explicitly rasterizing vector/text layers first. A pixel selection cannot partially transform an editable object layer: clear that selection or rasterize the layer. These cases produce a clear message instead of silently flattening objects.

Locked, position-locked, alpha-locked or hidden target layers cannot be transformed. Parent locks and visibility apply to descendants. Crossed perspective corners, folded mesh triangles, crossing outer mesh edges and tile-budget overflow are rejected. Transform coordinates are bounded to ±32768 artwork pixels; canvas dimensions, margins and overscan still define the actual editable extent.

## Clipboard and artwork images

The Edit menu provides Cut, Copy, Paste into new layer, Paste into active layer and Duplicate selected pixels. Standard Cmd/Ctrl+X/C/V work while the canvas has focus. Cmd/Ctrl+Shift+V pastes into the active raster layer; Cmd/Ctrl+J duplicates selected pixels into a new layer without replacing the system clipboard.

Copy extracts pixels from the active layer, through the current selection and feather coverage. Without a selection it copies all painted pixels on that layer. Clipboard images retain alpha. Toon Pro's internal placement metadata preserves the original artwork coordinates, including negative overscan; images copied from other applications default to the frame center. Copying a vector/text layer produces a pixel copy while keeping the source editable. Cut operates on unlocked raster layers with alpha lock off.

Pasting into a new layer, duplicating selected pixels and importing an artwork image select the new layer and start basic positioning. Apply or cancel that positioning gesture with Enter/Escape. Creating the image layer and positioning it are separate undo operations. Pasting into the active raster layer respects its existing selection and paint locks.

Use the **Import image** icon in the **Layers** footer, or **File → Import image as artwork layer…**, to add a PNG, JPEG, WebP, BMP or TIFF supported by the local Qt image plugins. The importer creates a separate layer named after the file, preserves transparency, centers the image and fits oversized images inside the output frame while preserving aspect ratio. Transform handles open immediately, with canvas focus ready for Enter to apply or Escape to cancel positioning; cancelling positioning keeps the imported layer. Undo removes the import. Playback pauses and any pending layer-opacity edit commits before the file chooser opens. Cancelling the chooser adds no layer. Reference import remains separate and never contributes to movie/frame exports.

Clipboard and artwork imports are limited to 64 million source pixels. Empty transparent images, placement outside the drawing extent, locked destination folders, more than 64 layers and the shared 1024-tile project limit are rejected without partially changing the document. Originals are not overwritten. Deleting or undoing an image layer needs no confirmation dialog.

## Retouch brushes

The Retouch group contains separate Smudge, Mixer, Blur, Sharpen, Dodge and Burn tools. Size ranges from 1–512 pixels; strength is a percentage. Tablet pressure affects dab diameter and strength. A stroke respects the raster selection, feathering, layer/folder locks and alpha lock, and commits as one undo operation. Escape restores the pre-stroke pixels.

These are deliberately simple native algorithms: Smudge carries nearby source pixels along the drag; Mixer blends the carried source with 35% foreground color before applying stroke strength; Blur averages a 3×3 neighborhood; Sharpen compares against that local average; Dodge/Burn move RGB values toward lighter/darker values while preserving alpha. They are not physical pigment simulation, a wet reservoir or adjustment layers. Existing sampled brush tips, dynamics and ABR compatibility remain described in [brush settings](brush-settings.md) and [brush compatibility](brush-compatibility.md).

## Unavailable actions and feedback — 0.14.2

The canvas shows the system forbidden cursor when the current tool cannot act in its context. The bottom bar explains the restriction while the pointer is on the canvas. Clicking or pressing the pen briefly highlights the reason with a warning icon; it does not open a dialog or change artwork. Resolving the restriction or leaving the canvas clears the hint. Runtime document failures remain visible for eight seconds, with the latest hover hint restored afterward. Long messages fit narrow windows with elision; their complete text remains available to accessibility and the shared delayed tooltip.

Checks cover incompatible layer types, hidden/full-locked layers and parent folders, alpha-lock erasing, missing vector paths, path geometry position locks, empty pixel selections, missing sampling reference layers, hidden guides, and artwork/selection-boundary transform restrictions. A failed transform preparation retains its reason until relevant context changes, avoiding repeated pixel scans on hover. Clicking a locked guide handle explains how to unlock it while still selecting the guide.

Raster-style brushes, erasers and shapes remain valid on vector layers. Bucket, gradient and retouch tools require raster layers. Selection and sampling are independent of artwork layer locks. Space/middle-button panning and Alt/Option temporary sampling remain available when drawing is blocked. Pen eraser ends use the same eraser availability and vector erasing behavior as the Eraser tool. Width/color/opacity edits remain possible under a position lock; geometry changes explain their restriction. Harmless no-ops, such as erasing empty space or simplifying an already-simple path, do not produce alerts.

## Editable vector brush strokes

Create a vector layer using the pen icon in Layers, then draw with the same tools in **Drawing**, including imported sampled brushes. The stroke uses the raster brush engine while retaining its centerline, captured pressure/tilt/rotation, seed, native brush settings and tip/texture/dual-tip images. Original strokes rebuild from the recorded dabs; editing their geometry repositions those dabs along the new path. Existing sampled brush pointers and stabilization remain active. Imported ABR tips retain the same native compatibility limits on either layer kind.

**Toolbox → Vector Editing → Path Edit** selects a stroke. Its three property tabs provide:

- **Transform:** drag the stroke to move it, drag corner/edge handles to resize, or the handle above the box to rotate. Shift constrains corner proportions or rotation steps.
- **Nodes:** move anchors and incoming/outgoing curve handles. Alt-drag an anchor to create a curve control; Shift mirrors the opposite handle. Ctrl-click on a selected path inserts a node. Delete removes a selected node when the remaining path is valid, otherwise the selected object.
- **Width:** drag width handles across the path; click the selected path to add a width control. Reset clears the width profile.

Stroke width, color and opacity remain editable. Width and opacity sliders preview while dragging and commit once on release; Escape restores the original value. These controls change the selected object, leaving its brush resources and captured input attached.

In the Nodes tab, **Simplify selected path** and **Simplify layer** reduce anchors within the chosen tolerance. Simplification preserves necessary curve and width detail, so some paths legitimately keep their nodes. **Simplify Brush** applies this reduction only in the swept region. **Width Brush** thickens or thins nearby sections with adjustable radius and strength. Each canvas gesture creates one undo entry, and Escape cancels it. Since 0.14.3, local correction brushes target the source centerline and its captured symmetry copies, including mirrored and radial copies after object transforms. Editing any copy changes the shared source, so all linked copies update; overlapping copies apply width strength once. Simplification checks deviation across copies, and width resampling accounts for the longest transformed copy. Independent scattered stamps remain outside correction-brush targeting. Hidden/locked layers and inherited folder locks are respected; position lock prevents geometry changes.

**Vector Nudge** joins the Vector Editing group in local **0.76**. Put its brush over a contour, press and drag the local area into place. **Radius** (1–256 artwork pixels) sets the original affected neighborhood; **Strength** (1–100%) scales the drag with smooth falloff. Pen pressure also scales the push. A drag is evaluated from its original source snapshot, so extra move events do not repeatedly deform the artwork. Curves are locally subdivided when needed; object identity, widths and recorded brush resources remain attached. Raster painting is not affected by this tool.

The canvas previews the deformation. Release commits one Undo; Escape, focus interruption and lost contact cancel it. Object/layer transforms and captured symmetry use artwork-space metrics. Position locks and path-morph animation block Nudge with a reason. Curved symmetry can have singular or unreachable push positions; those edits are refused atomically with a shorter-drag hint. Ordinary vector paths and well-conditioned symmetry copies retain editable source after save/reopen. Tool catalogs migrate the new Nudge/Ellipse entries once and retain deliberate removal thereafter.

The ordinary Eraser on a vector layer removes editable strokes. **Vector Eraser** has **Whole / Segment / Intersection** modes in local **0.76**. Whole removes touched strokes. Segment removes touched Bézier segments between their existing nodes. Intersection trims touched intervals between geometric centerline crossings on the active vector layer; existing nodes do not create artificial cuts. With no crossing, a touched stroke is removed as a whole; a closed contour with fewer than two distinct crossings also uses this fallback. Tangential touches and coincident spans are not crossing boundaries. The retained pieces keep editable curves, width profiles and recorded brush source; an eraser sweep commits once and supports Undo/Redo. Opened fragments lose their fill. It does not inspect other vector layers or infer intersections from raster paint. Locked geometry and destructive edits to path-animated sources retain their restrictions. Work is bounded to 65,536 flattened edges and two million edge comparisons; an over-budget operation leaves artwork unchanged.

Since 0.14.3, sampled-brush picking and erasing test painted alpha coverage, including transparent tip holes, transformed and mirrored stamps, continuous textures and captured selections/feathering. The normal screen-space picking tolerance still applies, so a narrow hole near a painted edge may select that edge. Vector strokes remain editable until explicitly rasterized from Layers. Raster bucket, gradients and retouching still require a raster destination.

Picking uses the renderer's stamp origin for footprints up to four million pixels. Exceptionally enlarged stamps use bounded query tiles; their antialiased fringe can differ slightly due to Qt's clipping/rounding, while interior transparent holes remain respected. Picking tests a stroke's own coverage, not preceding artwork for a manually stored alpha-locked brush source; the current vector drawing UI does not create such sources.

Since 0.45, brush captures also retain multiple-tip atlases, per-tip roots and deterministic selection, with primary sizes up to 1,024 pixels. These captures use format 4 inside project format 24; earlier captures retain their existing renderer size behavior. See [advanced tip controls](brush-settings.md#advanced-tips-and-quality-in-0450).

Vector brushes preserve captured selections and feathering during replay. Their texture and sampled tips still render to pixels: this workflow does not turn a bitmap stamp into resolution-independent SVG geometry. Changing geometry remaps the recorded samples; very large edits can spread stamps apart. Matrix transforms preserve the editable source; mesh warp continues to require explicit rasterization.

Version 0.14.3 caches each eligible stroke's accumulated paint before layer blending, so editing an earlier stroke reuses unchanged later paint while preserving blend order, alpha locks and captured feathering. Finishing a brush stroke seeds that cache from its existing paint. The cache is bounded to 64 MiB, including retained source/resources; individual entries are limited to 32 tiles. Large strokes and evicted entries use full replay. Editing and compositing remain synchronous CPU work; dense overlapping layers and unusually large strokes can still take longer.

Project format 14 retains embedded shared brush images independently of the brush library and regenerates editable-layer tiles on load. Versions 1–13 remain readable. Limits are 1,024 objects per layer, 4,096 per project, 16,384 nodes per path, 65,536 recorded dabs per stroke and 262,144 per project. Resource and tile limits also apply.

The standalone Text tool supports artwork text, font family, size, bold/italic, alignment, wrapping and line spacing. Existing text renders from shaped glyph outlines and can be transformed or rasterized. Fonts are not embedded, so another machine may use a fallback.

## 3D reference tools in 0.19.0

**3D Object**, **3D Camera** and **3D Rig** are individual tools in the 3D group and can be tagged or reorganized through Tool Management. The 3D Library supplies starter models and imports supported GLB/glTF assets into My Assets. Double-click or use Add to place a model in the shot's shared reference scene. Selecting these tools shows the object list and Model/Camera/Rig property tabs; drawing tools retain their compact drawing settings.

Object editing provides move/rotate/scale modes, axis values, reset, duplicate/delete, names, visibility and locks. Camera editing provides orbit/pan/dolly, fit all/selected, perspective/orthographic projection, lens/height/distance/orbit/elevation and a camera lock. Drags preview live and commit as one artwork-history operation. Choose a raster or vector artwork layer above the 3D reference to draw; paint and pixel-editing tools do not modify model geometry. This milestone uses fixed simple lighting and a texture/solid toggle. Both PNG exports exclude the 3D reference. [Full scope and limits](requirements.md#3d-reference-milestone--0160).

**3D Rig → Rest** edits a model instance's rest skeleton. Create a root skeleton or a 22-joint humanoid template, add child/root joints, double-click names to rename, and select a parent from the hierarchy-aware list. Delete removes the selected branch and can be undone. Joints use absolute model-local coordinates: moving or reparenting a joint leaves its children in place. Select a joint or bone on the canvas and drag in the plane facing the camera; Shift reduces movement to one tenth. Front/Side/Top gives orthographic views for depth placement and changes the saved camera, respecting its lock. XYZ sliders retain exact entry for other positions. Escape cancels a drag; a completed gesture is one Undo step.

Mirror duplicates an unpaired branch across the model's local center plane, links its corresponding joints, and uses the opposite parent where one exists. A branch with an off-center, unpaired parent must have its parent mirrored first. The mirrored-edit toggle applies subsequent joint position edits to the paired side. The skeleton display toggle hides editor handles only; it does not modify the model. Each instance owns its skeleton (up to 256 joints), so editing a duplicate does not change its source or global library asset. Locked/hidden targets cannot be edited. The skeleton is saved with the project and stays outside PNG exports. Binding locks rest structure, names and positions until the instance is unbound; the shared hierarchy still allows joint selection.

## Skin binding and weight painting

Select a model with rest joints, open **3D Rig → Weights**, and click the link icon to bind it. Binding runs in the background and creates up to four normalized influences per vertex from distances to the rest joints and their outgoing bone segments. These are starting weights for correction, not automatic anatomical rigging. The status row reports binding and visible-surface preparation without moving controls. A stale result is rejected if its target changes.

Choose a joint in the shared hierarchy. The heat legend runs from blue at zero influence through cyan and yellow to red at full influence. The three brush tabs are **Add**, **Subtract** and **Smooth**. Radius is 1–250 logical screen pixels; strength is 0–100 percent and is multiplied by pen pressure. Painting changes front-visible vertices under the brush, leaving hidden/rear vertices protected. Smooth moves the selected influence toward the falloff-weighted mean of the front-visible vertices currently under the brush; it is not mesh-topology smoothing. Sparse geometry therefore limits how precisely a weight boundary can be painted.

Weights remain normalized with no more than four influences per vertex. Reducing a vertex's only influence requires first giving it another joint influence. A completed stroke is one Undo action; Escape cancels it. Binding and unbinding also support Undo. Weight painting does not alter raster artwork or the immutable source model.

Use **Bend check** to inspect deformation temporarily. Choose X, Y or Z and adjust that axis from −90 to 90 degrees; the selected joint's rotation also affects its descendants. While bent, painting is disabled and the reset icon returns to the rest shape. Changing the selected joint/model, leaving Weights or switching away from 3D Rig clears the check. Bend angles and weight-brush settings are transient: Save resolves pending numeric entry, but they do not become saved poses or add artwork history.

The scissors icon unbinds the instance and enables Rest editing again. Unbinding removes its weights and current pose; Undo restores them. Bindings, weights and poses belong to the placed instance, remain independent after duplication, and are saved in project format 14 / scene schema 4. They do not modify the global library asset. Imported glTF skins, mirrored weight painting, weight transfer and reusable rig/pose assets remain deferred. All 3D reference geometry, heat colors and editing handles remain excluded from sheet and movie-frame PNG exports.

## Current-pose editing

Select a bound model and open **3D Rig → Pose**. The existing joint tree remains available; names and rest-joint structure stay locked until unbinding. Pose changes belong to the placed instance and are saved with the project. Selecting Rest or Weights temporarily displays that model at rest, preserving its saved pose; the Weights Bend check remains a separate, temporary inspection setting. Returning to Pose or drawing above the reference restores the current posed model.

**FK** rotates the selected joint and its descendants. Click X, Y or Z beside its rotation controls to select the canvas ring axis, then drag the ring; the paired sliders and fields set exact local angles. Rotations use the model's resting axes, with local X/Y/Z applied in that order. Select and drag a root joint to translate the whole skeleton, or use its **Body position** XYZ controls. Body position moves all roots together. Shift slows canvas gestures to one tenth; Escape cancels a pending edit.

**IK** uses a selected endpoint with a parent and grandparent forming two nonzero bones. Click the link icon or drag the endpoint to create a two-bone control. Use Target/Pole tabs to choose which canvas handle or XYZ values to move. The pole sets the bend direction. Unreachable targets retain the request and display a concise reach/limit status while the chain uses its reachable solution. Pin keeps the target fixed in model-local coordinates when the body or parent joints move. Moving the entire 3D object moves its pins too; this is not a world-space floor constraint. FK controls for joints directly driven by a pinned chain are disabled until unpinned. Rotating a joint in an unpinned IK chain hands that chain back to FK. Editing another unpinned IK chain that shares its controlled joints transfers control to the newly edited chain. Independent unpinned controls follow parent and body movement.

Enable **Joint limits**, select X/Y/Z, and set that axis's minimum/maximum. Limits remain within ±180 degrees and always include zero; they constrain the local rotation, including IK results. Mirror swaps the whole current pose across paired joints and the rig's local mirror plane. Reset selected removes its rotation and IK controls touching it; resetting a root also clears body position. Reset all clears rotations, body translation and IK controls while retaining joint limits. These actions and completed value/canvas drags are undoable. Save resolves an unfinished number; Undo or Escape cancels an active entry before earlier history is changed.

The saved current pose includes rotations, root translation, limits and IK targets/poles/pins. It is not a named reusable pose asset. Imported skins, rest-joint orientations, general multi-bone/full-body IK, animation and a reusable rig/pose library remain outside this milestone. Posed models remain drawing references and do not appear in either PNG export.

## Named palettes and artwork text in 0.34.0

## Photoshop brush descriptors in 0.34.0

ABR import now reads supported modern preset descriptors as well as sampled tip pixels. Real preset names and settings are associated by sample UUID rather than file order, so several presets can share the same tip correctly. Computed round tips become native round brushes. Supported mappings include diameter, angle, roundness, flips, spacing, computed hardness, size/angle/roundness dynamics, opacity/flow transfer and supported scatter/count controls. Pressure, tilt, stylus wheel, fade, direction and rotation controls map where the source descriptor and native engine support them.

Every imported preset retains compatibility details, including settings transferred, clamps, defaults and skipped features. Texture/dual-brush definitions, color dynamics, wet mixing, bristle tips, tool-preset behavior and exact Photoshop rendering are not reproduced. Unsupported descriptor types fall back to independently decoded sampled tips with a report; damaged known descriptors fail the import without altering the library. Source packs are unchanged. Native presets keep their original behavior.

The binary reader was independently implemented from [Adobe's descriptor specification](https://www.adobe.com/devnet-apps/photoshop/fileformatashtml/); brush field names and controller selectors were cross-checked against the maintained [ag-psd ABR reader](https://github.com/Agamnentzar/ag-psd/blob/master/src/abr.ts). These mappings provide useful native approximations, not a promise of Photoshop brush-engine equivalence.
