Images and character model sheets

Keep visual references nearby and organize character views independently of painted layers.

These instructions follow the current source build. Public 0.75 packages can differ.
In this chapterKeep reference images separateBuild a model sheetPair views with color rolesChoose the right kind of reuse

Keep reference images separate

References imports images for visual study without placing them into the exported artwork. Navigate the reference view independently from the canvas. With Eyedropper active, click/drag a reference image to sample its pixels into the foreground; choose another tool to resume reference panning. Import image as artwork layer is the deliberate alternative when the image should become document pixels.

Build a model sheet

Panels → References → Model Sheets organizes named characters and their reference views. Add supported images and label them as construction references. These remain reference sources rather than automatic rigs or generated sheets. In the managed dashboard, each independent drawing/shot owns its native library; sibling document tabs do not automatically synchronize character records.

  1. Add a character with + beside the character chooser.
  2. Choose Turnarounds, Expressions or Costumes.
  3. Import one or several source images; the library embeds bounded copies and preserves originals.
  4. Select a thumbnail to study it; use drag-to-pan, wheel zoom, Fit or precise zoom.
  5. Rename, move category or remove a sheet from its context menu; library edits support Undo.
Keep in mind

A multi-image import is one operation and leaves the library unchanged if a file fails.

The library is shared among shots only inside the same native payload. Current managed documents each contain one shot, so no cross-document synchronization is implied.

Pair views with color roles

Character Color Models store named swatches by shared role identity. Use reference views to compare construction while checking the approved palette or preparing explicit recoloring. Image reference and color-model state have separate controls; changing the selected character does not repaint existing pixels.

Choose the right kind of reuse

Project Assets retains original media in the .toonstudio folder; References provides editor study material; Light Table pins embedded movable snapshots over the canvas; Symbols share editable artwork. These have different update/export semantics. None should be described as an automatic live asset link unless that workflow explicitly implements it.
