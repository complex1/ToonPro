Drawing / LOCAL 0.76 SOURCE

Editable vector strokes and paths

Retain brush centerlines, adjust curves and widths, and clean intersections without flattening the source.

These instructions follow the current source build. Public 0.75 packages can differ.
In this chapterDraw editable strokesUse Path EditClean a contourErase geometricallyUse shapes and text

Draw editable strokes

Create a Vector layer in Layers and paint with the same Drawing tools, including supported sampled brushes. The recorded source retains centerline, captured pressure/tilt/rotation, seed, settings and embedded brush images. Existing marks replay with their captured resources even if the brush library later changes. Raster-style output from sampled tips still has bitmap detail; an editable stroke does not make that tip resolution-independent.

Use Path Edit

Choose Toolbox → Vector Editing → Path Edit and select a path. Transform moves/scales/rotates the object. Nodes edits anchors and incoming/outgoing handles; Alt-drag creates a control, Shift mirrors the opposite handle, Ctrl-click inserts a node and Delete removes a valid selected node or object. Width shows local controls; click the selected path to add one. Selected width, color and opacity remain editable.

Clean a contour

Simplify selected path/layer reduce anchors within tolerance; Simplify Brush limits reduction to a swept area. Width Brush thickens/thins locally. Vector Nudge pushes an original local neighborhood with radius, strength and pressure; each drag evaluates from its starting snapshot and creates one Undo. Position locks and path-morph sources retain their geometry protections.

Erase geometrically

Vector Eraser offers Whole, Segment and Intersection. Segment uses existing Bézier segment boundaries. Intersection uses geometric centerline crossings on the active vector layer rather than arbitrary nodes; retained fragments keep source curves, widths and brush resources. With no suitable crossing, it removes the touched stroke as a whole. Tangencies, coincident spans and raster paint are not crossing boundaries. Work/resource limits can refuse an oversized edit without publishing partial results.

Use shapes and text

Line, Rectangle, Ellipse, Polygon, cubic Curve and three-point Arc can produce editable paths on vector layers. Stroke/fill properties control their appearance. The standalone Text tool creates editable Unicode text on Text layers; font/style changes preview live. Fonts are not embedded, so another computer can substitute a fallback. Rasterize explicitly before mesh warping vector/text artwork.
