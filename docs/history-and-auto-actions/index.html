History and Auto Actions

Navigate retained artwork edits and replay a supported workflow as one validated operation.

These instructions follow the current source build. Public 0.75 packages can differ.
In this chapterNavigate HistoryRecord a workflowSupported operation scopeReplay atomically

Navigate History

Open Panels → History. Click a retained state or use its Undo/Redo controls. Current state is marked; later redo states are dimmed and a retained saved state is labeled. A new edit after going back removes the redo branch. History is document-session state and resets on load. Retention is up to 50 commands within the memory budget; Oldest retained state means earlier steps are gone.

Record a workflow

Open Panels → Auto Actions, add/name an action, press Record and perform supported operations. Stop keeps the steps; recording again appends. Replay targets the active drawing/layer using relative selection offsets, not original source IDs. Step checks skip individual operations; context actions reorder or remove them. Rename, Duplicate and Delete manage the action library.

Supported operation scope

Recording covers supported raster layer/folder creation and properties, relative layer selection, layer effects, selection fill, Point bucket with source/gap/expansion settings and applied basic raster move/scale/rotate. Brush strokes/settings, Enclose, gradients, masks, selection creation, perspective/warp, vector/multi-layer transforms, file dialogs, export, animation and 3D are not recorded. Unsupported committed artwork stops recording with a reason.

Replay atomically

The engine first evaluates enabled steps on an isolated document copy. Invalid destinations, locks or missing relative sources leave target artwork/selection/history unchanged and identify the failed step. Successful edits create one Undo. Auto Actions live globally beside workspace preferences, separately from the project and brush organization history. No Photoshop .atn import, shortcut assignment, cloud synchronization or action sets are implemented.
