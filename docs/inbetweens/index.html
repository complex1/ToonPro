Optional local RIFE suggestions

Generate raster transition suggestions between two pose drawings, inspect them and insert one reversible batch.

These instructions follow the current source build. Public 0.75 packages can differ.

Set up the optional runtime

RIFE is a separate pinned helper/model, not a Python editor dependency or a cloud service. Run scripts/setup_rife.py before configuring the app; TOON_RIFE_ROOT selects its directory, default .deps/rife. The helper uses the official rife-ncnn-vulkan 20221029 release with a compact v4.6 model. Opening the panel never downloads anything. Without runtime files Generate is disabled with a setup message.

python3 scripts/setup_rife.py
cmake -S . -B build -DCMAKE_PREFIX_PATH="/path/to/Qt/6.10.3/platform"
cmake --build build --target ToonPro --parallel 3

Generate and review

Select two distinct drawing cels on the same animation track or choose Start/End in Panels → In-betweens. Every frame/On twos controls spacing inside the existing endpoint interval; the ending pose does not move. Choose easing, then Generate. The preview supports thumbnails, drawing scrub, playback, pan/zoom and fit. Insert drawings commits ordinary raster cels as one Undo. Existing intermediate drawings block the operation instead of being replaced.

Choose alpha treatment deliberately

White background retains the model RGB result over its temporary white input matte. Transparent line art, the remembered first-use default, reconstructs alpha from a detected single ink color. It is suitable for single-color outlines. White marks disappear and colored marks reconstruct to that ink, so use White background for multicolor art/white details. Original endpoint drawings and their alpha remain unchanged.

Know what is generated

RIFE uses the two rendered source drawings, excludes other tracks/paper/camera/guides, and flattens supported source sublayers. It does not preserve editable vectors, choose acting or retain internal layer separation. Unsupported effects, masks, animation properties, Symbols or 3D sources are refused. Limits include 64 suggestions, 16-megapixel canvases and conservative generated-tile/history budgets. Initial runtime acceptance targets Apple Silicon macOS; other archives do not imply verified packaged support.
