Drawing / LOCAL 0.76 SOURCE

Detect perspective from an image

Analyze straight-edge families locally, review a proposal and add ordinary editable guides.

These instructions follow the current source build. Public 0.75 packages can differ.
In this chapterChoose a sourceReview detected evidenceCorrect deliberatelyScope and ownership

Choose a source

Select a layer and open Edit → Detect perspective, its Layers context action or the Guides sparkles button. The source can be locked because detection reads it. Context captures include relevant transforms/masks/effects and clipping. Image file reads an external supported image without inserting it into artwork. For exact registration with a placed reference, import/position it first and analyze its layer.

Review detected evidence

Auto, One-point and Two-point choose the target model. Detail changes edge sensitivity. Directions selects proposed finite vanishing points or parallel families; Density controls displayed divisions. Strong match and Review suggested describe support, not calibrated accuracy percentages. Use Adjust to exclude/restore edges or move proposed handles; Fit image/Fit guides and normal pan/zoom help inspect distant points.

Correct deliberately

Region limits the evidence to a selected rectangle. Two lines creates a manual direction by dragging two distinct edges; their intersection is a vanishing point, or parallel evidence creates a ruler. Reset clears region/exclusions/manual corrections and detects again.

  1. Choose source and target model.
  2. Inspect edges and direction choices.
  3. Limit a noisy source to a useful region.
  4. Correct weak directions with Two lines or handle drags.
  5. Click Add guides to commit one Undo, then enable snapping when desired.

Scope and ownership

Accepted guides are independent snapshots of geometry. Moving/deleting the image later does not regenerate them. Source pixels remain unchanged. Detection is native offline C++ analysis, requiring no account, AI model or upload. Organic forms, distortion and mixed perspective can need manual judgment. Automatic three-point/fisheye recovery and linked recipes are absent. Inputs/previews and edge counts are bounded; document changes invalidate stale proposals.
