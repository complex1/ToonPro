Platform packaging recipes ↗

macOS

Install Xcode Command Line Tools, CMake 3.24+, zlib and Qt 6.10.3 for macOS. Select QtBase, QtSvg and QtMultimedia; Qt Test is needed for tests. Use a C++20 compiler. Set the Qt path below to your installation.

git clone https://github.com/complex1/ToonPro.git
cd ToonPro
cmake -S . -B build -DCMAKE_PREFIX_PATH="/path/to/Qt/6.10.3/macos" -DTOON_ENABLE_FILAMENT=OFF -DTOON_ENABLE_EXPERIMENTAL_3D=ON -DBUILD_TESTING=ON
cmake --build build --config Release --parallel 4
ctest --test-dir build -C Release --output-on-failure --parallel 2
open build/ToonPro.app

Windows

Use an x64 Visual Studio 2022 developer shell with C++20 support, CMake 3.24+, Qt 6.10.3 msvc2022_64 and zlib. Set CMAKE_PREFIX_PATH and ZLIB_ROOT to the actual SDK and zlib locations. Qt Multimedia and SVG are required. The commands below use PowerShell.

git clone https://github.com/complex1/ToonPro.git
cd ToonPro
cmake -S . -B build -DCMAKE_PREFIX_PATH="C:/Qt/6.10.3/msvc2022_64" -DZLIB_ROOT="C:/path/to/zlib" -DTOON_ENABLE_FILAMENT=OFF -DTOON_ENABLE_EXPERIMENTAL_3D=ON -DBUILD_TESTING=ON
cmake --build build --config Release --parallel 4
$env:PATH = "C:\Qt\6.10.3\msvc2022_64\bin;$env:PATH"
ctest --test-dir build -C Release --output-on-failure --parallel 2
.\build\Release\ToonPro.exe

Linux source

Linux is a development target; public distribution is deferred. Use a C++20 compiler, CMake 3.24+, zlib development headers, Qt 6.10.3 gcc_64 and the matching XCB/OpenGL/audio runtime dependencies. GUI tests need a display or Xvfb. Video encoding needs a working codec runtime; see packaging notes.

git clone https://github.com/complex1/ToonPro.git
cd ToonPro
cmake -S . -B build -DCMAKE_PREFIX_PATH="/path/to/Qt/6.10.3/gcc_64" -DTOON_ENABLE_FILAMENT=OFF -DTOON_ENABLE_EXPERIMENTAL_3D=ON -DBUILD_TESTING=ON
cmake --build build --config Release --parallel 4
ctest --test-dir build -C Release --output-on-failure --parallel 2
./build/ToonPro
What is being built?

Source version 0.76.0, including current development tools. Published 0.75.0 preview packages have an earlier project flow. These commands are build recipes; platform verification results belong to the corresponding build.

Then make your first drawing.

  1. Open the app and choose New project → Drawing.
  2. Give the project a name and choose its local folder.
  3. Choose New drawing, set the canvas dimensions and background, then create it.
  4. Choose a brush in Tools, set a foreground color and draw on the editable layer.
  5. Save the document with Cmd/Ctrl+S.

Check before packaging.

CTest covers application behavior; physical tablet feel, platform codecs and clean-machine packages need their own acceptance checks. Run the packaging scripts only after the relevant platform checks pass.
