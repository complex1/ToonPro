Type and visual identity

Space Grotesk supplies the reading and interface type; Bricolage Grotesque adds expressive headings. Both are served locally under the SIL Open Font License. The website’s simple vector mark and UI symbols are project artwork.

Space Grotesk license · Bricolage Grotesque license

The browser playground

The small ink canvas is an illustrative website interaction. It uses browser drawing APIs and does not embed, reproduce or benchmark Toon Pro’s native brush engine. You can download your own doodle locally.

Privacy and local preferences

This static site has no analytics, account system or tracking cookies. Search runs in your browser. Saved features use local storage on your browser and can be removed by unsaving them or clearing site storage. External links use their destination’s own policies.

Build and release boundaries

This site documents current source 0.76.0; published preview 0.75.0 packages may differ. Source code availability does not establish pricing or an application license. Dependency notices and platform packaging requirements remain in the repository.
