# Toon Pro drawing icons

These 19 SVGs are original Toon Pro artwork created for the 0.51.0 compact drawing pass. They are not copied from Lucide. Their 24-unit canvas, 2-unit rounded strokes and currentColor treatment match the existing outline family.

The semantic registry in src/icons.h/.cpp defines stable names and labels. appIcon resolves toon-* names from this resource directory using the same proportional high-DPI renderer and theme colors as the bundled Lucide icons. The upstream Lucide attribution in the sibling directory remains unchanged.
