Feedback on the current interface

The neutral theme, compact icon rail, visual brush samples, exact-entry pairs and canvas handles are a strong foundation. Keep these. The redesign should improve hierarchy and grouping more than shrink individual controls.

  • Fragmented brush workflow. Tools, size presets and quick properties appear as distinct surfaces (S035–S040, S449–S451). Give them one predictable vertical home while preserving their dock identities.
  • Weak emphasis between common and occasional actions. Long tool lists and dense inspector headers compete with the canvas. Keep current brush, size and essential properties close; open organization and detailed editing deliberately.
  • Some panels spend considerable height on empty or unrelated space. Use active-page measurement and independent scrolling rather than compressing widgets further. Keep headers and completion actions pinned.
  • Narrow layouts need composition changes. S034, S036, S038, S040 and S042 demonstrate why uniformly scaling the whole workspace will not work. At compact widths, use one brush drawer and one persistent right dock.
  • Do not hide meaningful distinctions. Keep layer names, current values, blend modes, Adjust stamp On/Off, and Apply/Discard/Cancel as text. Familiar actions can remain icons.

Proposed workspace

Wide desktop: 48 px toolbox, 220 px brush dock, flexible canvas, 264 px right dock. Brush list gets remaining height; presets and quick settings remain directly below it. Right upper tabs expose Colors, References and Navigator, with Layers always below. This tab grouping is a proposed default, subject to artist review; panels remain independently floatable in the native app.

Compact desktop: 900 px review frame, toolbox, canvas and 244 px right dock. A persistent brush button opens the brush drawer. This adds one access step when changing brushes, so validate it on the Huion before making it the default. Quick-access pins, current brush size and wrench remain visible. Below 800 px the same composition activates automatically. Phone-size drawing is not a verified target; the concept prioritizes compact desktop/tablet windows.

The paper illustration is original concept artwork used to assess hierarchy. It is not a new engine feature or a captured production document.

States and interaction coverage

The prototype demonstrates brush selection/search, size presets with synchronized entry, palette swatches and hex entry, upper-panel tabs, layer selection/add/duplicate/delete/Undo, visibility and lock appearance, wide/compact mode, brush drawer, drawing mode, zoom and dialogs. States opens empty layers, populated layers, pending stamp and an import-error example. Layer changes are local simulation only.

Color-picker gradients, thumbnails, artwork layers, blend mode, tag filtering, pressure behavior and advanced graph editing are layout studies. Actions with informational feedback do not execute application commands. Dialogs do not implement the complete brush library. Recording/playback and 3D/animation layout redesign are deferred; their current surfaces remain mapped below.

Prototype Tab toggles drawing mode only with body focus so ordinary keyboard focus traversal remains available. Native Tab behavior must retain the repository's input, pen-contact and pending-gesture guards.

Review method and limits

Read the handoff brief, coverage and repository UI guidelines; reviewed contact-sheet overviews of all 451 manifest screenshots, including 306 primary images and 145 supplementary images. Overview review establishes layout patterns, not full-resolution verification of every control. Screen/control inventory supplies traceability. Physical pen feel, performance, high-DPI rendering and native docking require application testing.

This folder is a design deliverable. The running Qt application, README implementation status and existing application source have not been changed. Further detailed screen layouts, exhaustive state designs and artist approval are still required before treating this as an implementation-ready redesign of all 39 families.
