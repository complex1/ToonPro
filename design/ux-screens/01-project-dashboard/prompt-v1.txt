Use case: ui-mockup
Asset type: Screen 01 of a native desktop anime drawing and animation application, Toon Pro. First-launch project dashboard, high-fidelity design image for UX review, not a marketing graphic.
Primary request: Render one polished, calm, credible desktop application screen showing a user's saved projects, with direct Create/Open actions. The app starts here, not on an editor or timeline. Wide landscape 16:10 composition, approximately 1600 x 1000. Show the entire flat application surface straight-on, edge-to-edge; no monitor, desk, perspective, browser, annotations or surrounding presentation canvas.
Style: Adobe Spectrum-inspired restrained charcoal UI, original Toon Pro identity, compact precise line icons like Lucide, clean readable sans-serif typography, professional desktop density balanced with breathing room. Modest 6 px corners, subtle one-pixel borders, no pill-heavy styling, gradients, glass, neon or exaggerated shadows. Main background #222222, title bar #282828, cards #303030, borders #444444, primary text #e8e8e8, secondary text #b5b5b5, silver primary action #bdbdbd with dark text. The thumbnail artwork supplies all vivid color. No blue selected controls.
Composition:

2. Header: left aligned large exact title "Projects", and a small secondary line "Pick up where you left off." Right aligned outlined folder icon + "Open project" and a slightly stronger silver plus icon + "New project" button. Creation and opening have visible text, not ambiguous icons alone.
3. One horizontal control row: directly accessible text tabs "All projects", "Pinned", "Archived" at left with All projects selected by a short silver underline and brighter text; no duplicate nav. 4. Main content: exactly six project cards in a disciplined 3-column x 2-row grid, evenly spaced. Each card has a substantial 16:9 artwork thumbnail, a clean short title underneath and muted last-opened metadata. A tiny three-dot action at right of each title row. Do not show a canvas, frames, timeline, layers panel or editing tools anywhere. Do not show project type badges, progress, scene counts, clip sections, task dashboards or an extra create-project card.
