# Animation project

Version 1 · 5 November 2026 · Proposed UX, not implemented.

Browse animations/shots and create a new animation. Every animation entry opens an editor for exactly one shot. Duration and FPS belong to each animation.

See [the project flow](../project-flow.md) for authoritative navigation and content semantics. All names, artwork, edit times and durations in the image are fictitious placeholders. The project dashboard reference supplies the shared visual style; it is not an edit target.

Generation: built-in image_gen tool. [Complete prompt](prompt-v1.txt) · [Generated screen](animation-project-v1.png).

Static images do not establish keyboard/focus/drag behavior or file/storage limits. Future implementation must use accessible names, visible focus, comfortable targets and the shared 600 ms tooltip delay.
