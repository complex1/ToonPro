A workspace controls where panels appear. It does not change your artwork, convert the document to another mode, or replace your brushes. You can move from illustration to animation work by changing the arrangement around the same project.

Open hidden panels from **Panels**. Most panels are resizable docks: move them, put them into tab groups or float them beside the main window. **Toolbox** is different. It is a narrow icon column that occupies the side of the workspace and contains tool groups or standalone tools.

## Pick an arrangement for today's task

Use **View → Workspace**, or the Workspace button in the top toolbar.

- **Illustration** keeps Tools, brush sizes and Properties at the left, with Colors, References, Navigator and Layers at the right. Timeline is hidden to give the drawing more height.
- **Anime** places Timeline under the canvas and keeps Frame Properties available beside the drawing controls.
- **Storyboarding** raises Shots in the left column, helping you move among boards without keeping a large timeline open.
- **Animatics** gives Timeline more height and keeps Shots and Frame Properties close for audio, camera and timing work.
- **Compact drawing** puts drawing controls in a drawer, avoiding a permanently reserved controls column on a small window.

All presets keep Toolbox and Quick access. Panels not emphasized by a preset remain available from the Panels menu. Switching layouts pauses playback and preserves the current drawing context. Finish an active stroke, transform or unfinished value before switching so a layout change does not resolve an edit unexpectedly.

## Know the three tool surfaces

**Toolbox** chooses a group or standalone tool. **Tools** shows the members of the selected group, or just the selected standalone entry. **Properties** changes to the active tool's controls.

This separation lets you create a small daily group without deleting the larger brush library. The same tool definition can appear in several groups and share its settings. **Duplicate** makes an independent tool when you want a different configuration.

Tools places its tag filter and search on one line. Search by name or tag, then use **All tags** to remove a tag restriction. Filtering does not change the active brush merely because its row disappears. **Clear tool filters** restores the list when nothing matches.

Choose **Tools → ⋯ → Icons only** for a compact grid. Return to the named list when you need to inspect names or reorder tools. Hover previews and icons for their names rather than enlarging every row.

Open **Panels → Tool Management**, or **⋯ → Manage tools**, to edit Groups and Tools. Groups can have names, tags, a label color and a built-in or uploaded icon, with a checked membership list. Tools supports assigning tags or label colors to several definitions together. These colors organize the interface; they do not change paint. A group tag matches its members while browsing that group without overwriting the tools' personal tags.

Removing a placement from a group differs from deleting its brush definition through Brush Management. Use removal to simplify a daily group while retaining the tool elsewhere. Use organization Undo when correcting group or tag changes, and artwork Undo when correcting a drawing.

## Choose and retain drawing colors

In **Colors**, select the foreground or background chip, then use the hue strip and saturation/brightness field. Hex entry provides an exact color; the swap icon exchanges foreground and background. Changing a color does not repaint earlier marks.

The palette chooser browses local named palettes. Use **+** to save the current color as a named swatch, and the options menu for **New palette** or palette management. Right-click a swatch to rename, replace or delete it. Browsing palettes keeps the current foreground until you use a swatch. For project-specific character roles shared across shots, use **References → Color Models** instead of relying only on a local artist palette.

## Put favorite actions in Quick access

Use **Quick access → +** at the top to pin the current tool or foreground color. You can also choose another tool or color and add navigation actions: **Hand**, **Zoom in**, **Zoom out**, **Fit sheet** and **Reset view rotation**.

Click a pin to use it. Right-click to move it left or right or remove it. Removing a tool pin does not delete the tool. Pins and their order are remembered across projects, with room for up to 48 entries.

A useful small set for line art is your ink brush, eraser, a dark drawing color, white, Hand and Fit sheet. A background-painting set might replace white with two frequent palette colors and add a texture brush. Keep the row focused on actions you actually use during a stroke sequence.

## Reuse brush sizes

Open **Panels → Brush Preset** for the size grid. Clicking a tile changes the active Brush or Eraser size without replacing its tip, color or dynamics. Use **+** to add a size; right-click a tile to edit or remove it. **⋯ → Reset sizes to defaults** restores the starting set.

Saved sizes are local preferences shared across projects. They are not complete brush presets, and changing the size list does not enter artwork Undo. Mask, retouch and vector-correction brushes keep their own size controls. For a complete independent brush configuration, duplicate the tool instead.

## Navigate without moving artwork

Hold **Space** and drag, use the middle mouse button, or select **Hand** to pan. The wheel zooms around the pointer. **View → Fit sheet** fits the production paper, and **Actual size** sets a 100% working-view scale. On a high-density display, that scale uses logical interface pixels rather than guaranteeing one physical display pixel per image pixel.

**Navigator** provides a miniature canvas with view controls. Canvas zoom and rotation are drawing aids; they do not create animation keys. The top **AA** control is **Canvas smoothing (AA)**. It changes the appearance of zoomed or rotated artwork on screen and leaves stored pixels and exports unchanged.

## Draw with the panels hidden

With the canvas focused, press **Tab** for Drawing mode. The canvas and Quick access remain while ordinary panels and project controls hide. Press Tab again or **Return to workspace** to restore the previous arrangement.

Tab continues normal keyboard navigation inside fields, panels, menus and dialogs. Finish a pen gesture before changing modes. Save, Undo/Redo and canvas tool shortcuts remain usable while Drawing mode is active.

## Save a personal layout

Arrange the panels, then choose **View → Workspace → Save workspace as…**. Use **Update saved workspace** after refining an active custom layout. Built-in presets cannot be overwritten. **Reload workspace** restores the active saved arrangement; **Previous layout** swaps with the layout before the last successful change.

**Manage workspaces…** lets you use, rename or delete personal layouts. A saved layout includes dock positions, tab groups, sizes, visibility and relevant inspector state. It does not capture your artwork, active brush, tool groups, Quick access contents, canvas view, shortcuts or main-window geometry. Those distinctions let you improve the workspace without unintentionally changing the drawing setup.
